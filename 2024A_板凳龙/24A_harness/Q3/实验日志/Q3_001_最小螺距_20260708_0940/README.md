# Q3_001 最小螺距（初版，判据不充分——已被 Q3_002 修正）

- **目的**：用"龙头到边界时全局间隙恰为0"（$f(p)=G(\theta_h=9\pi/p;p)=0$）求最小螺距。
- **结果**：$p=0.420217$ m，但**后验证未通过**。
- **关键发现（重要）**：在 $p=0.420217$ 下沿盘入向外扫描 $G(\theta_h)$，发现最小间隙 $G=-0.0299$ 出现在 $r=4.5847$ m（**边界外侧**），而非边界处。说明间隙 $G$ 随盘入是**振荡下降**（非严格单调），碰撞会在龙头到达边界**之前**（更大半径）发生。
- **结论**：仅用边界处 $G=0$ 的判据**不充分**，会低估最小螺距。正确判据应为"整个盘入到边界过程 $G\ge0$"，即 $m(p)=\min_{\theta_h\ge9\pi/p}G(\theta_h;p)=0$。
- **后续**：见 `Q3_002_最小螺距修正` 用修正判据重解。
