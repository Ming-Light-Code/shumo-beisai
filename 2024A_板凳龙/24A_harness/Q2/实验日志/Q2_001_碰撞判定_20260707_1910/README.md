# Q2_001 碰撞判定

- **目的**：实现 Q2_v1 方案——OBB-SAT 全穷举判碰 + 粗扫描定位跳变区间 + 对龙头极角二分收敛，求盘入终止时刻与状态，生成 `result2.xlsx`。
- **与上次差异**：首个 Q2 实验，代码基于 Q1 位置模型扩展（新增矩形构造、SAT clearance 函数、粗扫描+二分逻辑）。
- **结果一句话**：终止时刻 $t^\ast=412.473838$ s（晚于问1的300s窗口，属预期），临界碰撞对为龙头板凳与第8节龙身板凳，恰好相切（$G\approx10^{-12}$）；sanity check 全部通过；已生成 result2.xlsx + 可视化 + 论文表格。

## 关键发现
- 首次碰撞并非发生在问1讨论范围（300s）内，而是在 $t\approx412.47$ s，此时龙头半径已收缩到约 $r=b\theta_0^\ast\approx2.29$ m。
- 全局间隙 $G(t)$ 呈衰减振荡下降（振荡周期对应龙头逐圈扫过内圈候选对），整体单调趋于0，验证了判据实现正确。
- 全穷举候选范围验证了"仅龙头触发碰撞"这一直觉在本参数下成立，但触发候选对的板凳序号随时间/半径变化（34→9），佐证了不预设固定简化窗口、直接全穷举的决策是稳健的。
