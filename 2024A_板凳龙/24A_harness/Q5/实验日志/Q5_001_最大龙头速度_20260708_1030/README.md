# Q5_001 最大龙头速度（20260708_1030）

## 目的
舞龙队沿问题 4 设定的复合路径（盘入螺线→S形调头曲线→盘出螺线）匀速行进，求龙头最大行进速度，使全部 224 个把手速度均不超过 2 m/s。

## 方法
利用速度递推公式对 $v_{head}$ 的**线性齐次性**：给定几何构型（龙头弧长坐标 $s_{head}$）时，各把手速度 $v_i=K_i(s_{head})\cdot v_{head}$，$K_i$ 只依赖几何、与 $v_{head}$ 数值无关。因此只需在 $v_{head}=1$ 下对全路径 $s_{head}$ 做**全局最大化** $K_{max}=\max_{s_{head},i}K_i(s_{head})$，即得 $v_{head}^{\max}=2/K_{max}$。

- 复用 Q4 的 `geometry_q4.py`（复合轨道 track(s)）与链式递推（弦距=板间距，brentq 求解）。
- 三级步长（0.2→0.01→0.0005 m）+ `minimize_scalar` 精化，并用 $S=200$ 与 $S=350$ 两种扫描范围验证远场收敛。

## 关键结果
- 临界弧长坐标 $s_{head}^*=14.479970$ m（龙头已越过 $P_{out}$，进入盘出螺线约 0.86 m）。
- **全局最大放大系数 $K_{max}=1.60479338$**，瓶颈为第 3～7 节龙身（并列，因均落在调头曲线弧1内、弧内自相似使增量恒为1）。
- **龙头最大行进速度 $v_{head}^{\max}=1.246266$ m/s**。
- 与方法学一致（同样用完整刚体链递推+全局数值搜索）的公开参考文献 $1.248181$ m/s 相差仅 0.15%，作为支持性证据；公开解法因各队建模精细度不同分散较大（约 0.4~1.6 m/s 不等），本结果的核心可信度主要来自内部 sanity check（三级步长收敛、缩放后精确复现 $\max v_i=2.000000$），文献吻合为补充印证而非唯一依据。
- 题目未要求 Q5 产出 `result5.xlsx` 等模板文件（仅要求给出 $v_{head}^{\max}$ 数值），故本问无结果文件模板合规项，答案以 `outputs/q5_answer.csv` + 本文档 + 总结 md 呈现。
