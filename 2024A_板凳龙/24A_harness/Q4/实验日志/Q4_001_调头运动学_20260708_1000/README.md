# Q4_001 调头运动学（20260708_1000）

## 目的
构造 S 形调头曲线（两段相切圆弧，前弧半径=后弧2倍，切盘入/盘出螺线），回答"能否缩短调头曲线"，并求龙头 1 m/s 沿"盘入螺线→S曲线→盘出螺线"复合轨道、−100~100 s 每秒 224 把手的位置与速度。

## 方法
- **复合轨道**：所有把手沿同一条弧长参数化轨道 track(s)（s=0 于 P_in, t=0）。盘入/盘出段用单调样条反解螺线弧长，调头段为两圆弧解析式。
- **链式递推**：相邻把手直线弦距=板间距，brentq 求解。
- **速度递推**：弦距不变对 t 求导，弧长参数化下速度大小=|ds_i/dt|。
- **设计优化**：半径比扫描 + 切点半径扫描。

## 关键结果
- 切点 P_in=(−2.7119,−3.5911)，R1=3.0054 m，R2=1.5027 m，**调头曲线长 LS=13.6212 m**（调头耗时 13.62 s）。
- 全场速度（逐秒采样）0.540~1.422 m/s，龙头恒 1 m/s；最大值出现在调头紧弧处把手（连续时间真实峰值更高，约 1.6 m/s，见 Q5 的精确定位）。
- **设计问题（正式答案）：不能。** 固定切点于调头空间边界（与本问运动学模型一致）时，半径比 R1/R2 不影响调头曲线长度——因 α1≡α2 恒定、R1+R2 由切点位置唯一确定，与比例无关，故 LS≡13.6212 m 是不变量。
- **扩展讨论（非正式答案）**：若放松为允许切点半径本身内移，LS 可随之单调缩短（如 r_entry=3.0m 时 LS=8.92m），但该方向缺乏约束下界、数学上退化为开放问题，不作为本题正式结论。
