# Q4_v1 调头运动学 —— 代码实现方案

> 依据 `code-plan`。几何构造 + 复合轨道弧长参数化 + 沿轨链式/速度递推。

## 1. 问题类型
解析几何（相切圆弧构造）+ 弧长参数化曲线 + 刚性链沿轨道递推（根查找）+ 一维优化（设计问题）。

## 2. 输入输出
**输入**：$p=1.7$ m（$b=p/2\pi$）；调头边界 $R=4.5$ m；板凳几何（间距 2.86/1.65 m，矩形不需要，本问不判碰）。
**输出**：
- `result4.xlsx`：官方模板，位置 sheet(449×202) + 速度 sheet(225×202)，时间 −100..100 s，6 位小数，node i→行同 Q1。
- 论文：−100/−50/0/50/100 s × 节点 {0,1,51,101,151,201,223} 位置速度。
- 设计问题：$L_{给定}$（$R_1=2R_2$）、$L_{最短}$、结论（能/否）。

## 3. 算法步骤（到可执行公式）

### 3.1 螺线与切点
$b=1.7/2\pi$。$\theta_c=R/b$（$P_{in}$ 处极角，$r=b\theta_c=4.5$）。
$P_{in}=(b\theta_c\cos\theta_c,\ b\theta_c\sin\theta_c)=4.5(\cos\theta_c,\sin\theta_c)$，$P_{out}=-P_{in}$。
切向 $t_{in}\propto(\cos\theta_c-\theta_c\sin\theta_c,\ \sin\theta_c+\theta_c\cos\theta_c)$（单位化）。外法线 $n_1$（取 $P_{in}\cdot n_1>0$），$c=P_{in}\cdot n_1$。

### 3.2 S 曲线（$R_1=2R_2$）
$R_1+R_2=|P_{in}|^2/c=20.25/c$（S 形外切，$\sigma_1=\sigma_2=-1$ 推得）。$R_2=(20.25/c)/3,\ R_1=2R_2$。
$O_1=P_{in}-R_1 n_1$，$O_2=-P_{in}+R_2 n_1$。junction $J=O_1+R_1\,(O_2-O_1)/\|O_2-O_1\|$。
弧1：$O_1$、$R_1$、$P_{in}\to J$；弧2：$O_2$、$R_2$、$J\to P_{out}$。遍历方向由切点处切向= 龙头行进方向（$-t_{in}$，盘入向内）确定；弧长 $L_1=R_1\alpha_1,\ L_2=R_2\alpha_2$，$L_S=L_1+L_2$。
**验证**：切点处两侧切向连续（螺线↔弧1 于 $P_{in}$，弧1↔弧2 于 $J$，弧2↔盘出 于 $P_{out}$），端点吻合。

### 3.3 复合轨道 track(s)（弧长参数，s=0 于 $P_{in}$，+s=龙头行进方向）
- $s\le0$（盘入）：$a=-s$，用预计算样条 $\theta(a)$ 反解弧长（$a=S_{sp}(\theta)-S_{sp}(\theta_c)$，$\theta\ge\theta_c$），点 $=(b\theta\cos\theta,b\theta\sin\theta)$，切向沿向内。
  - $S_{sp}(\theta)=\tfrac b2[\theta\sqrt{\theta^2+1}+\operatorname{asinh}\theta]$。
- $0\le s\le L_S$（调头）：$s\le L_1$ 在弧1，否则弧2；点=绕圆心旋转，切向=旋转半径 ±90°。
- $s\ge L_S$（盘出）：$a=s-L_S$，$\phi(a)$ 同样条反解，点 $=-(b\phi\cos\phi,b\phi\sin\phi)$，切向对应。
- 切向 $T(s)$ 统一取 +s 方向单位向量。

### 3.4 链式递推（每个 t）
龙头 $s_0=t$。for $i=1..223$：解 $s_i<s_{i-1}$ 使 $\|track(s_{i-1})-track(s_i)\|=L_i$（$L_1=2.86$，余 1.65）。
`brentq` on $g(s_i)=chord-L_i$，括号 $[s_{i-1}-3L_i,\ s_{i-1}-10^{-9}]$（chord 随 $s_{i-1}-s_i$ 增大而增，单调）。

### 3.5 速度递推（每个 t）
$P_i=track(s_i)$，$T_i=T(s_i)$。$\dot s_0=1$。
for $i=1..223$：$\dot s_i=\dfrac{(P_{i-1}-P_i)\cdot T_{i-1}}{(P_{i-1}-P_i)\cdot T_i}\,\dot s_{i-1}$；速度大小 $v_i=|\dot s_i|$（弧长参数 ⇒ $|T_i|=1$）。

### 3.6 设计问题
$R_1+R_2=D=20.25/c$ 固定。对 $R_1\in(0,D)$：$O_1=P_{in}-R_1n_1$，$O_2=-P_{in}+R_2n_1$（$R_2=D-R_1$），算 $J$、$\alpha_1,\alpha_2$、$L(R_1)$。`minimize_scalar` 求最短；与 $R_1=2R_2$ 比较，答能否变短。

## 4. 现成 vs 自建
- 螺线弧长、相切圆弧构造：解析几何标准（现成公式）。
- 复合轨道参数化 + 沿轨链式/速度递推 + 设计优化：自建，已到可执行公式。

- S1 量纲：m、m/s、rad。
- S2 边界：$t=0$ 龙头在 $P_{in}$（$r=4.5$）；龙头速度恒 1；$t<0$ 结果应与"纯盘入螺线"一致（可与 Q1 同类交叉验证）。
