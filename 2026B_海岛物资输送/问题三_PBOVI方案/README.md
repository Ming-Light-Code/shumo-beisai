# 问题三：天气随机先验信息已知条件下的规划

## 方法概述

本方案基于仵博博士论文《动态不确定环境下的智能体序贯决策方法及应用研究》提出的**基于点的在线值迭代算法（Point-Based Online Value Iteration, PBOVI）**，将问题三构建为马尔可夫决策过程（MDP），通过骨架路径枚举 + 在线前向与或树搜索 + 值函数逼近 + 分支界限剪枝进行求解。

### 参考论文方法对照

| 论文章节 | 方法 | 本方案应用 |
|---------|------|-----------|
| §2.1 马尔可夫决策过程 | MDP 形式化定义 | 将船舶航行构建为状态-动作-转移-奖励四元组 |
| §2.3 可分解信念状态空间压缩 | 状态特征分解 | 15 维可分解状态特征向量用于值函数逼近 |
| §3.3 基于点的在线值迭代算法 | AND-OR 树 + 深度优先 + 剪枝 | 工作点处的在线前向搜索决策 |

## 求解流程（8 阶段）

```
Phase 1: 骨架枚举
  └─ DFS 生成 379 条 B→...→E 宏观路径候选

Phase 2: 基础策略 MC 评估
  └─ 对每条骨架运行 200 次随机天气仿真（贪婪策略：正常天气工作，雷暴天气停留等待）

Phase 3: API 第 1 轮 — 拟合值函数
  └─ 收集 (状态, 回报) 样本 → 岭回归拟合 V_Z(s), V_M(s)

Phase 4: ADP 策略评估
  └─ 使用值函数指导工作/离开决策，评估 Top 50 骨架

Phase 5: API 第 2 轮 — 在线策略重采样
  └─ 使用当前 ADP 策略重新采样 → 重新拟合值函数

Phase 6: 在线前向树精化（§3.3 PBOVI）
  └─ 工作点处构建深度 D=4 的 AND-OR 树，分支界限剪枝

Phase 7: MC 验证
  └─ 2000 次随机天气仿真，统计期望 Z、M 和成功率

Phase 8: 确定性回放
  └─ 固定天气序列 (seed=42) 产生确定性的排程示例
```

## 关键策略设计

### 1. 工作点风暴策略
- **正常天气**：工作（消耗 CWORK[0]，获得收益）
- **雷暴天气**：idle_stay（原地停留，保留连续工作配额），仅在工作配额耗尽或时间不足时离开
- 此策略避免了在雷暴天立即撤离导致的额外往返消耗

### 2. 补给采购自适应安全余量
- 采用 z-score 方差驱动采购量
- 预算充裕时 z→2.0（多买，确保雷暴也不缺）
- 预算紧张时 z→0.5（保守购买，优先保留资金 M）

### 3. 骨架瞄准校验
- 采购仅在 skeleton[si]==supply_node 时触发
- 工作仅在工作点匹配当前骨架目标时触发
- 防止船舶在补给/工作点反复循环

### 4. 在线前向树搜索（论文 §3.3 核心）
- **AND 层**：动作分支（工作 / 离开）
- **OR 层**：天气分支（正常 / 雷暴）
- 叶子节点使用值函数近似评估
- 分支界限剪枝加速搜索

## 模型局限性与改进方向

1. **成功率约 60%**：由于 30×30 网格上长途奔袭的资源消耗较高，约 40% 的天气序列会导致资源耗尽
2. **骨架枚举上限 10000 条**：可能遗漏更优的多次往返工作路径
3. **值函数为线性近似**：对于非线性价值结构拟合能力有限
4. **改进方向**：可推广为在线滚动时域 MPC + 场景树随机规划
