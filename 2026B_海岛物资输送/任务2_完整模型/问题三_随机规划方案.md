# 问题三：天气随机先验信息已知条件下的规划方案

## 一、问题形式化

### 1.1 场景参数

| 参数 | 值 |
|------|-----|
| 网格 | $30\times30$ |
| $B$ | $(1,15)$ |
| $E$ | $(30,15)$ |
| $S_1, S_2$ | $(12,16), (21,16)$ |
| $W_1, W_2, W_3$ | $(6,21), (15,9), (24,24)$ |
| $O_0, H_0, F_0$ | $100, 150, 100$ |
| $M_0, Z_0$ | $750, 200$ |
| $L_{\max}$ | $400$ |
| $T_{\max}$ | $90$ 天 |
| $P(\text{正常})$ | $0.8$ |
| $P(\text{雷暴})$ | $0.2$ |

### 1.2 随机动态规划形式

状态 $S_t = (x_t, y_t, O_t, H_t, F_t, M_t, Z_t, c_t, w_t, t)$，与问题二定义一致。

最优策略 $\pi^*$ 满足 Bellman 方程：

$$V^*(S_t) = \max_{a_t \in A(S_t)} \mathbb{E}_{w_t}\left[V^*(\mathcal{T}(S_t, a_t, w_t))\right]$$

精确DP因状态空间爆炸（$30\times30\times\text{连续资源}$）不可行。

## 二、期望值约束规划（EVCP）

### 2.1 核心思想

将随机消耗替换为概率加权期望值：

| 消耗类型 | 正常天气 | 雷暴天气 | **期望值** |
|----------|:---:|:---:|:---:|
| 移动 O/格 | 2 | 8 | $\mathbf{3.2}$ |
| 移动 H/格 | 3 | 4 | $\mathbf{3.2}$ |
| 移动 F/格 | 2 | 3 | $\mathbf{2.2}$ |
| 停泊 O/天 | 1 | 3 | $\mathbf{1.4}$ |
| 停泊 H/天 | 1 | 3 | $\mathbf{1.4}$ |
| 停泊 F/天 | 1 | 2 | $\mathbf{1.2}$ |
| 作业 O/天 | 5 | 8 | $\mathbf{5.6}$ |
| 作业 H/天 | 4 | 6 | $\mathbf{4.4}$ |
| 作业 F/天 | 3 | 6 | $\mathbf{3.6}$ |

补给价格不变（$p_O=2, p_H=1, p_F=2$）。作业收益不变（$Y_1=20, Y_2=15, Y_3=28$），连续作业上限不变（$WM=[4,5,3]$）。

### 2.2 算法流程

```
EVCP在线决策 (t = 1, 2, ..., 90):
  1. 观测: w_t ← 当日天气
  2. 消耗: 按实际天气 w_t 扣除当日动作资源
  3. 规划: 从当前状态出发，以期望消耗调用CP搜索
  4. 执行: 执行CP方案的首个动作
  5. 转移: S_{t+1} ← 状态更新
  6. 若 (x,y)=E: 终止
```

CP引擎与问题二完全相同，仅消耗参数替换为期望值。

## 三、关键距离分析

| 从→到 | B | S1 | S2 | W1 | W2 | W3 | E |
|--------|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| B | 0 | 12 | 21 | 11 | 20 | 32 | 29 |
| S1 | 12 | 0 | 9 | 11 | 10 | 20 | 19 |
| S2 | 21 | 9 | 0 | 20 | 13 | 11 | 10 |
| W1 | 11 | 11 | 20 | 0 | - | - | 30 |
| W2 | 20 | 10 | 13 | - | 0 | - | 21 |
| W3 | 32 | 20 | 11 | - | - | 0 | 15 |

**关键观察**：
- $S_1$ 是核心枢纽：距 $B$ 12格、距 $W_1$ 11格、距 $W_2$ 10格、距 $S_2$ 9格
- $S_2$ 是东侧枢纽：距 $W_3$ 11格、距 $E$ 10格
- $W_3$ 收益最高（28/天），紧邻 $S_2$
- $W_2$ 收益最低（15/天），但距 $S_1$ 最近（10格）

## 四、候选路径骨架

### 4.1 全覆盖骨架（含全部三个作业点）

$$B \to S_1 \to W_1 \to S_1 \to W_2 \to S_1 \to S_2 \to W_3 \to S_2 \to E$$

旅行总距离：
$$12+11+11+10+10+9+11+11+10 = 95 > 90 \quad \times$$

超出时限，不可行。需精简。

### 4.2 双作业骨架（W1 + W3）

$$B \to W_1 \to S_1 \to S_2 \to W_3 \to S_2 \to E$$

旅行距离：$11+11+9+11+11+10 = 63$ 天

剩余 $90-63=27$ 天用于作业：
- $W_1$: 3天作业（连续，$WM_1=4>3$），$Z$ 增量 $+60$
- $W_3$: 采用停泊—再作业策略，$WM_3=3$，可安排约20工作天
  - 3天+停1天+3天+停1天+3天+停1天+3天+停1天+3天+停1天+3天
  - 即 $6\times3=18$ 工作天 + 5 停泊重置天 = 23天
  - $Z$ 增量 $+18\times28 = 504$

总 $Z$ 预期：$200+60+504 = 764$，总天数 $63+3+23=89 \leq 90$。

### 4.3 高收益骨架（仅W3）

$$B \to S_1 \to S_2 \to W_3 \to S_2 \to E$$

旅行距离：$12+9+11+11+10 = 53$ 天

剩余 $90-53=37$ 天用于 $W_3$ 作业。最大化工作天：
- 以3天为一块，中间停泊1天重置
- $k$ 块工作：$3k + (k-1) \leq 37 \Rightarrow k \leq 9$
- $9\times3=27$ 工作天 + 8 停泊重置 = 35天
- $Z$ 增量 $+27\times28 = 756$
- 总 $Z = 200+756 = 956$

### 4.4 方案对比

| 骨架 | 旅行 | 剩余 | W1作业 | W3作业 | 预期Z | 天数 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 全覆盖 | 95 | -5 | - | - | 不可行 | >90 |
| 双作业 | 63 | 27 | 3天 | ~18天 | ~764 | ~89 |
| 高收益 | 53 | 37 | 0 | ~27天 | ~956 | ~88 |

**高收益骨架（仅W3）具有最高的预期Z**。

## 五、鲁棒性增强

### 5.1 安全裕度补给

纯期望值策略在连续雷暴时可能资源不足。引入安全系数 $\alpha$：

$$\text{采购需求} = (1+\alpha) \times \text{期望需求}$$

$\alpha=0.1$ 时的采购量约增加10%，为雷暴日提供缓冲。

### 5.2 蒙特卡洛验证

对任一候选方案，按 $P(\text{正常})=0.8$ 采样 $N=1000$ 条天气序列，逐日模拟资源消耗，统计：

- 抵达 $E$ 的概率（成功率）
- $Z, M$ 的均值与分布

### 5.3 在线重规划的回退策略

若实际天气比预期更差（资源低于安全阈值），触发紧急重规划：
- 缩减或取消后续作业
- 提前前往补给点
- 最坏情况：放弃作业，直达 $E$ 确保存活

### 7.2 在线决策循环

```matlab
function [Z_final, M_final] = solve_q3_online()
    % 初始化状态
    state = init_state_q3();
    rng('shuffle');
    
    for day = 1:90
        % 观测天气
        w = rand() < 0.8;  % true=正常, false=雷暴
        
        % 消耗当日资源（按实际天气）
        state = consume_today(state, w);
        
        % EVCP规划
        plan = evcp_plan(state);
        
        % 执行动作
        [state, arrived] = execute_action(state, plan.action);
        
        if arrived, break; end
    end
    
    Z_final = state.Z; M_final = state.M;
end
```

### 7.3 蒙特卡洛评估

```matlab
function [success_rate, Z_mean, M_mean] = mc_evaluate(plan_func, N)
    successes = 0; Zs = []; Ms = [];
    for i = 1:N
        weather = rand(1, 90) < 0.8;
        [ok, Z, M] = simulate_plan(plan_func, weather);
        if ok, successes = successes + 1; Zs(end+1) = Z; Ms(end+1) = M; end
    end
    success_rate = successes / N;
    Z_mean = mean(Zs); M_mean = mean(Ms);
end
```
