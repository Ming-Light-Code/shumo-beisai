# 2026B 问题三 CP 期望值求解方案

## 方法概述

本方案采用**约束规划 (Constraint Programming) + 期望值消耗参数**方法，将随机天气问题退化为确定性优化问题，通过路径骨架 DFS 枚举 + 工作天数枚举 + 停泊重置策略 + 上界剪枝进行求解。

### 核心思路

- **期望值消耗**：将 P(正常)=0.8, P(雷暴)=0.2 的随机天气平滑为期望消耗参数
  - E[移动] = (3.2, 3.2, 2.2) / 格
  - E[停泊] = (1.4, 1.4, 1.2) / 天
  - E[作业] = (5.6, 4.4, 3.6) / 天
- **差异化安全裕度**：补给采购时对受雷暴影响最大的燃油 O 应用更高裕度
  - O: ×1.25 (雷暴移动消耗 4 倍放大)
  - H: ×1.05 (最大 1.5 倍放大)
  - F: ×1.05 (最大 2 倍放大)
- **停泊重置策略**：在作业点遇到连续作业上限时，停泊 1 天重置计数器，实现 W3 的 4 轮 × 3 天 = 12 天深度作业
- **上界剪枝**：最乐观假设剩余天数全部在 W3(收益 28/天) 工作，快速排除不优分支

### 验算

Z = 200(初始) + 3×20(W1) + 12×28(W3) = 200 + 60 + 336 = 596 ✓

## 策略要点

1. **W3 深度作业**：利用停泊重置将 W3 的 3 天连续上限扩展为 4 轮 × 3 天 = 12 天，收益 336。W3 是收益最高的作业点 (28/天)，集中资源在此作业是最优策略。

2. **W1 顺路收割**：前往 S1 途中经过 W1 仅需 11 格，用 3 天净赚 60 Z，机会成本低。

3. **S1→S2 蓝色走廊**：两个补给平台在同一纬度 (y=16)，9 格东行直达，无绕路。

4. **补给精准化**：每次补给仅采购至下一补给点所需，避免超买浪费资金。差异化安全裕度确保 O 有充足余量应对雷暴消耗。
