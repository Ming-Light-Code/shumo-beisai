# 任务三：单船宏观网络滚动时域MILP模型

## 文件说明

| 文件 | 说明 |
|------|------|
| `task3_macro_mpc.m` | 主求解程序，包含 MPC + MILP + 蒙特卡洛验证 |
| `README.md` | 本文档，模型说明与使用指南 |

## 题目背景

2026年东南大学数学建模竞赛 B 题"海岛物资输送问题"任务三。

- 海域：30x30 网格
- 起点 B(1,15)，终点 E(30,15)
- 补给平台：S1(12,16)，S2(21,16)
- 作业点位：W1(6,21)，W2(15,9)，W3(24,24)
- 初始资源：O=100, H=150, F=100, M=750, Z=200
- 载重上限：400 单位
- 时间限制：90 天
- 天气：每日独立，P(正常)=0.8，P(雷暴)=0.2

## 模型方法

### 1. 宏观网络简化
用 7 个功能点 (B, S1, S2, W1, W2, W3, E) 代替 900 个网格节点，移动弧时长等于曼哈顿距离。

### 2. 滚动时域 MPC
- 每日规划 H=20 天的前瞻窗口
- 仅执行第一天的决策（一格移动/停泊/作业）
- 次日观测天气后重新求解

### 3. 两阶段 MILP 优化
- **Stage 1**：最大化目标物资 Z
- **Stage 2**：固定 Z 值，最大化剩余资金 M

### 4. 机会约束
每个未来时间步独立计算二项分布分位数，保证资源储备随规划时域单调递增。

### 5. 蒙特卡洛可靠性验证
对固定策略进行 10000 次独立天气模拟，计算 Wilson 95% 置信下界。

## 使用方法

```matlab
% 默认参数运行（随机生成天气）
result = task3_macro_mpc();

% 指定随机种子
result = task3_macro_mpc([], 2026);

% 指定天气序列
weather = ["正常"; "正常"; "雷暴"; ...];  % 90 天
result = task3_macro_mpc(weather, 2026);
```

## 依赖

- MATLAB R2026a 或更高版本
- Optimization Toolbox (intlinprog)

## 主要修复（相对于原始版本）

| 修复项 | 说明 |
|--------|------|
| 机会约束公式 | 每步独立计算分位数，保证单调性 |
| 已承诺目标约束 | 移除（单船场景无需此限制） |
| 撤离天数 | 动态计算（2x剩余曼哈顿距离） |
| 求解器参数 | lookahead 15→20，求解时 5s→15s，gap 2%→1% |
| 蒙特卡洛采样 | 5000→10000 |
| Stage 2 tie-breaking | ε值与M量级匹配 |

## 模型局限性

1. 宏观网络丢失网格级信息（不能中途停靠补给平台）
2. 确定性期望值规划而非真正随机规划
3. 前瞻窗口 20 天不足以覆盖 90 天全周期
4. 蒙特卡洛仅验证不定优化策略
