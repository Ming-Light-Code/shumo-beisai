## 方案三：基于混合整数线性规划（MILP）的事件驱动模型

### 1. 方法概述

将问题一分解为两层：

- **外层**：枚举所有可能的路径骨架（停靠点序列）——采用与解法一相同的 5^k 全枚举，确保覆盖 B 到 E 的所有中间点排列（含重复访问）；
- **内层**：对给定骨架，建立事件驱动的混合整数线性规划（MILP），以停靠点为事件节点，将逐日约束压缩为段间转移方程，调用 intlinprog 同时优化工作天数（整数变量）和采购量（连续变量）。

最终在所有可行骨架中取两阶段字典序最优解：先最大化目标物资 Z，再最大化剩余资金 M。

---

### 2. 数学模型

#### 2.1 符号约定

| 符号 | 含义 |
|------|------|
| P = [p_0, p_1, ..., p_{m+1}] | 路径骨架，p_0 = B，p_{m+1} = E，m 为中间停靠点数 |
| d_i | 第 i 段移动的曼哈顿距离（常量），i = 1,...,m+1 |
| n_w | 作业停靠点数量（骨架中 W1/W2/W3 的出现次数） |
| n_s | 补给停靠点数量（骨架中 S1/S2 的出现次数） |
| CM = (2,3,2) | 每格移动消耗 (O,H,F) |
| CW = (5,4,3) | 每日作业消耗 |
| WY_j 取值 {20,15,28} | 作业点 j 的单位天收益 |
| WM_j 取值 {4,5,3} | 作业点 j 的单次最大连续天数 |

#### 2.2 决策变量

对给定骨架，定义以下变量：

- w_j (整数, >=0), j = 1..n_w —— 第 j 个作业停靠点的工作天数
- buyO_k, buyH_k, buyF_k (连续, >=0), k = 1..n_s —— 第 k 个补给站的采购量
- O_i, H_i, F_i, M_i (连续, >=0), i = 0..m+1 —— 离开（到达）第 i 个停靠点后的资源状态

其中 i=0 对应起点 B，i=m+1 对应终点 E。

#### 2.3 段间转移方程

对第 i 段（从停靠点 i-1 到停靠点 i），i = 1..m+1：

- O_i = O_{i-1} - d_i * CM_O - w_i * CW_O + buyO_i
- H_i = H_{i-1} - d_i * CM_H - w_i * CW_H + buyH_i
- F_i = F_{i-1} - d_i * CM_F - w_i * CW_F + buyF_i
- M_i = M_{i-1} - (2*buyO_i + 1*buyH_i + 2*buyF_i)

其中 w_i 当且仅当第 i 个停靠点是作业点时取值对应的工作变量，否则为 0；buy 同理仅对补给站非零。

#### 2.4 约束条件

**资源非负性（离开停靠点后）**：

O_i >= 0, H_i >= 0, F_i >= 0, M_i >= 0  (i = 1..m+1)

**载重上限**：

O_i + H_i + F_i <= 120  (i = 0..m+1)

**总天数限制**：

sum(d_i) + sum(w_j) <= 30

**单次工作天数上限**（每个作业停靠点独立约束）：

0 <= w_j <= WM_j  (j = 1..n_w)

**补给站到达前资源非负**（关键约束，见 §3.2 论证）：

O_{i-1} >= d_i * CM_O, H_{i-1} >= d_i * CM_H, F_{i-1} >= d_i * CM_F

仅对补给停靠点 i（即 p_i 属于 S1 或 S2）施加。

**初始条件**：

O_0 = 35, H_0 = 45, F_0 = 30, M_0 = 240, Z_0 = 100

#### 2.5 目标函数

两阶段字典序优化：

- **阶段 1**：max Z = 100 + sum(w_j * WY_j)
- **阶段 2**：固定 Z = Z_max，max M_{m+1}

阶段 2 通过增加等式约束 sum(w_j * WY_j) = Z_max - 100（以一对不等式 <= 和 >= 实现）来固定 Z。

---

### 3. 模型核心论证

#### 3.1 事件驱动压缩的等价性

**命题**：在任意两个相邻补给站之间，逐日资源非负约束等价于段末（到达下一站时刻）资源非负。

**证明**：在任意两个补给站之间的所有天中，资源只消耗而不补充（补给仅发生在停靠点）。因此对于每种资源 R (属于 O, H, F)，其存量在段内单调非增。设段内第 t 天结束时存量为 R(t)，则

R(0) >= R(1) >= ... >= R(d_i + w_i)

若 R(d_i + w_i) >= 0，则对所有 t 有 R(t) >= 0。反之，若某 t 处 R(t) < 0，由单调性必有 R(d_i + w_i) < 0。因此段末非负当且仅当段内逐日非负。

这一性质使得模型无需按天展开 30 天的全部变量（那将需要约 7x30 = 210 个变量），而只用约 40 个停靠点级变量即可完整刻画约束。

#### 3.2 补给站到达前约束的必要性

在补给停靠点 i，采购发生在**到达之后**。段间转移方程给出的是采购**后**的状态：

O_i = O_{i-1} - d_i * CM_O + buyO_i

仅约束 O_i >= 0 不能保证到达时刻（采购前）O_{i-1} - d_i*CM_O >= 0——因为足够大的 buyO_i 可以使 O_i >= 0 成立，但到达时资源可能已为负，这在物理上不可行。

因此必须额外施加：

O_{i-1} >= d_i * CM_O

对 H、F 同理。在代码中以 -O_{i-1} <= -d*CM_O 形式纳入不等式矩阵。

对于非补给停靠点（作业点或普通网格点），buy 项为零，此时 O_i = O_{i-1} - d_i*CM_O - w_i*CW_O，O_i >= 0 即等价于到达前非负，无需额外约束。

#### 3.3 采购量为何可设为连续变量

题目要求所有资源量按非负整数单位计，理论上采购变量 buyO_k 等应为整数。本模型将其设为连续变量（非负实数），理由如下：

1. 等式约束的 RHS 项 -d*CM 全部为整数（d 是曼哈顿距离整数，CM 是整数）；
2. 目标函数在阶段 1 不涉及采购变量，在阶段 2 最小化总采购成本（等价于最大化 M_{m+1}），推动采购量取最小可行值；
3. 各资源的最小可行采购量由段内需求与当前存量的差值决定，该差值在整数初始值和整数消耗下为整数；
4. 尽管载重约束 O_i+H_i+F_i <= 120 破坏了约束矩阵的全幺模性，在本题的具体数据范围内，求解器返回的采购量在绝大多数情况下自然为整数。

若需严格保证整数性，可将 buyO/buyH/buyF 加入 intvars，但会增加求解时间约 3*n_s 个整数变量。

### 4. 算法流程

`
输入: 地图、初始资源、参数
输出: (best_Z, best_M, best_path, best_wdays)

1. 计算 7 个特殊点间的曼哈顿距离矩阵 dist[7][7]
2. 确定骨架最大长度 max_seq = min(7, 30 - dist(B,E))
3. best_Z = -inf, best_M = -inf

4. for seq_len = 0 to max_seq:
5.    枚举所有长度为 seq_len 的五进制序列（5^seq_len 条）
6.    映射为路径 pid = [B, 中间点序列, E]
7.    if pid 含相邻重复点: continue
8.    计算各段距离 travel[1..m+1] 及总和 total_travel
9.    if total_travel > 30: continue
10.   构建 work_idx / supp_idx 映射数组
11.   [feasible, Z, M, w] = milp_skeleton(...)
12.   if feasible and (Z > best_Z or (Z == best_Z and M > best_M)):
13.       更新最优解

14. 输出最优解
`

milp_skeleton 子过程：

1. 按变量布局构造 n_vars 维向量
2. 构造等式约束矩阵 Aeq (4*(m+1) 行)：O/H/F/M 四条平衡方程
3. 构造不等式约束矩阵 A：载重 (m+2 行)、总天数 (1 行)、工作上限 (n_w 行)、补给前非负 (3n_s 行)
4. 设置边界：下界全 0（除初值固定），上界全 inf（除初值固定）
5. 阶段 1：intlinprog(f1, intvars, A, b, Aeq, beq, lb, ub) -> Z_max
6. 阶段 2：添加 Z 固定约束后 intlinprog(f2, ...) -> M_max
7. 返回可行性、Z、M 和最优工作天数向量

---

### 5. 变量索引映射

MATLAB 数组为 1-based，变量在解向量中的位置如下：

| 变量组 | 数量 | 起始索引 | 说明 |
|--------|------|----------|------|
| w_1..w_{n_w} | n_w | 1 | 整数变量，各作业停靠点的工作天数 |
| buyO_1..buyO_{n_s} | n_s | off_bO+1 | 连续，各补给站的燃油采购 |
| buyH_1..buyH_{n_s} | n_s | off_bH+1 | 连续，淡水采购 |
| buyF_1..buyF_{n_s} | n_s | off_bF+1 | 连续，食物采购 |
| O_0..O_{m+1} | m+2 | off_O+1 | 连续，各停靠点后燃油 |
| H_0..H_{m+1} | m+2 | off_H+1 | 连续，淡水 |
| F_0..F_{m+1} | m+2 | off_F+1 | 连续，食物 |
| M_0..M_{m+1} | m+2 | off_M+1 | 连续，资金 |

其中 O_i 在 off_O + 1 + i，O_{i-1} 在 off_O + i。M_{m+1} 在 off_M + m + 2，即阶段 2 的目标变量。

### 6. 代码结构

文件 milp_task1.m 包含两个函数：

| 函数 | 行数 | 功能 |
|------|------|------|

### 7. 计算复杂度

| 项目 | 数值 |

| 预计总耗时 | 5-10 分钟（MATLAB R2020a+，Intel i7 或同级） |

### 8. 与解法一的优劣比较

| 维度 | 解法一（枚举+贪婪模拟） | 方案三（枚举+MILP） |
|------|------------------------|---------------------|
| 采购策略 | 各补给站独立贪心，买刚好够 | 所有补给站联合优化 |
| 容量瓶颈处理 | 瓶颈站判为不可行 | 可在前序站提前多买以绕过瓶颈 |
| 运行速度 | 约 1 分钟（纯数值模拟） | 约 5-10 分钟（LP 求解器开销） |
| 数学形式化 | 描述性（启发式论证） | 标准 MILP 框架，约束逐条形式化 |
| 依赖 | 无 | Optimization Toolbox |
| 逐日输出 | 天然产出（模拟中即逐日记录） | 需后处理展开（当前未实现） |

在本题的载重上限（120）和段间最大消耗的参数下，解法一的贪婪策略在实际运行中极大概率与 MILP 得到相同最优解。MILP 的理论优势更多体现在更严苛的参数场景（更小载重上限、更大段间消耗）中。

### 9. 已知局限

1. **采购量非整数变量**：设为连续实数，题目要求整数，未给出总幺模性证明；
2. **无逐日调度展开**：输出不含每日位置、每日行为、资源余量，需后处理补充；
3. **未输出采购量明细**：求解器中 buyO/buyH/buyF 未被提取和报告；
4. **依赖商业工具箱**：intlinprog 非开源，限制了可复现性；
5. **无进度指示**：枚举 5-8 万条骨架时用户无法获知当前进度；
6. **骨架枚举上限固定为 7**：max_seq = min(7, 30-9)，在极端参数下可能漏掉含 8+ 个中间点的路径；
7. **未与解法一交叉验证**：无自动对比机制确认两方法结果一致。

### 10. 后处理：从 MILP 解展开逐日调度（待实现）

给出 MILP 返回的最优骨架和最优工作天数后，可按以下步骤生成题设要求的完整输出：

1. 按骨架和曼哈顿路径确定每日的网格坐标；
2. 按段间转移方程反推每日结束时的 (O,H,F,M,Z)；
3. 在补给停靠点处插入采购事件，记录采购量；
4. 输出 30 天 x (位置, 行为, O, H, F, M, Z) 表格。

此功能可添加为 milp_task1 的一个后处理阶段，在确定最优解后调用。
