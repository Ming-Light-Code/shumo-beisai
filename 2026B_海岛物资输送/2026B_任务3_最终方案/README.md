# 2026B 海岛物资输送问题 —— 任务3 最终方案

## 问题概述

在 30×30 网格海域中，船舶从起点 B(1,15) 出发，需在 90 天内抵达终点 E(30,15)。
每日天气独立同分布：P(正常)=0.8, P(雷暴)=0.2。
船舶每日仅能观测当日天气，不可预知未来，但可利用天气概率先验进行策略优化。

目标：使抵达终点时目标物资 Z 最大；Z 相同时使剩余资金 M 最多。

### 关键参数

| 参数 | 值 |
|------|-----|
| 网格 | 30×30 |
| 时限 | 90 天 |
| 载重上限 | 400 |
| 初始 (O, H, F, M, Z) | (100, 150, 100, 750, 200) |
| 补给点 | S1(12,16), S2(21,16) |
| 作业点 | W1(6,21,20/天,max4), W2(15,9,15/天,max5), W3(24,24,28/天,max3) |
| 补给价格 | O=2, H=1, F=2 |

## 模型详解

### 模型一：期望消耗约束规划 (离线CP)

将随机天气问题退化为确定性优化问题：使用期望消耗参数
```
E[移动] = 0.8×(2,3,2) + 0.2×(8,4,3) = (3.2, 3.2, 2.2) /格
E[停泊] = 0.8×(1,1,1) + 0.2×(3,3,2) = (1.4, 1.4, 1.2) /天
E[作业] = 0.8×(5,4,3) + 0.2×(8,6,6) = (5.6, 4.4, 3.6) /天
```
引入差异化安全裕度（按雷暴放大倍数分配）：
- 燃料 O: ×1.25（雷暴移动放大 4×，停泊 3×，作业 1.6×）
- 淡水 H: ×1.05（最大放大 1.5×）
- 食物 F: ×1.05（最大放大 2×）

CP 搜索框架：路径骨架递归 (B→{W1,W2,W3,S1,S2}→...→E) + 工作天数枚举 + 三剪枝规则。

### 模型二：在线随机天气决策

滚动时域 CP 重规划：
- **消耗双轨制**：规划期用期望消耗（`cons_exp`），执行期用实际天气消耗
- **重规划触发**：天气变化时 + 每 5 天强制 + 生存模式激活时
- **生存优先模式**：当任一资源 < 1.5× 到最近补给点的期望需求时，强制直赴补给点
- **三场景加权评估**（`plan_scenario`）：对规划路径分别在正常(20%)/期望(60%)/悲观(20%)消耗假设下评估，取加权得分，防止过度乐观

### 模型三：MDP Monte Carlo Rollout

显式建模天气方差：
- 在每个决策点，对每个候选目标 np∈{W1,W2,W3,S1,S2}：
  - 假设先移动到 np，然后按 CP 基策略规划剩余路径
  - 生成 K=20 条独立天气轨迹，模拟完整执行
  - 计算平均 Z
- 选择 avgZ 最大的候选，执行其对应计划
- 计划中已扣除到 np 的期望旅行消耗

## 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 安全裕度 | O×1.25, H/F×1.05 | O受雷暴影响最大(移动4×放大)，需要最高裕度 |
| plan_scenario权重 | [0.2, 0.6, 0.2] | 60%基线(期望消耗是正确概率加权估计)，20%尾部分布 |
| 生存阈值 | 1.5× 到最近补给点需求 | 在资源真正枯竭前足够提前触发逃生 |
| 重规划周期 | 5天 | 平衡计算开销与天气响应速度 |
| MDP采样数 K | 20 | 每个候选~60次CP搜索，在线决策可接受(~12秒) |
| MC验证次数 N | 500 | 标准误~1.1%，足以可靠估计~7%量级成功率 |
| 补给估算 | 使用期望消耗(cons_exp) | 与CP规划一致，避免乐观假设 |

## 模型正确性保证

1. **CP搜索穷举性**：对5个候选点全排列+工作天数全枚举，上界剪枝不误剪
2. **索引正确性**：`get_supply_needs` 通过 `completed_wp` 参数追踪已完成工作点，消除索引错位
3. **MDP决策正确性**：Rollout采样结果直接决定执行的候选动作，`plan_from_candidate` 扣除旅行消耗后规划
4. **参数一致性**：文档与代码的参数完全同步（SAFETY_O=1.25, 生存阈值1.5×, 重规划5天）
5. **补给估算一致性**：`simulate_with_weather` 内的补给需求估算统一使用 `cons_exp` (含安全裕度期望消耗)
