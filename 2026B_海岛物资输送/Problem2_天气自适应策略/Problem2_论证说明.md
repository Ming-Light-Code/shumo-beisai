## 问题二：天气可观测条件下的自适应策略设计

> 事件驱动 MILP + 滚动时域优化（Receding Horizon） | 2026-07-19

---

### 1. 问题重述

在问题一基础上引入天气影响，天气分为正常（消耗同问题一）和雷暴（消耗显著增加）。每日仅能观测当日天气，无法预知未来，需实时制定行动决策。特别要求给出连续30天雷暴极端情形的最优方案。

---

### 2. 雷暴天气资源瓶颈分析

#### 2.1 消耗系数对比

| 行动 | 正常 O/H/F | 雷暴 O/H/F | O 倍数 |
|------|:----------:|:----------:|:------:|
| 移动/格 | 2/3/2 | **8**/4/3 | ×4 |
| 作业/天 | 5/4/3 | **8**/6/6 | ×1.6 |
| 停泊/天 | 1/1/1 | **3**/3/2 | ×3 |

初始 O=35，载重上限 120。雷暴下每格耗油 8 → 不补给最多移 4 格；两补给站间最多载油 ≈100 → 最多移 12 格。

#### 2.2 B→S1→E 直达与 B-stop 技巧

```
方案A: B→S1→E 直接 (无B-stop)
  B→S1(3格): O=35-24=11 H=45-12=33 F=30-9=21  负载65
  S1买: O需=64-11=53 F需=24-21=3
  买后: O=64 H=33 F=24 负载=121 > 120 ✗  刚好超1

方案B: B→S1→E (day1停泊B, 消耗3,3,2)
  B停: O=35-3=32 H=45-3=42 F=30-2=28
  B→S1(3格): O=32-24=8 H=42-12=30 F=28-9=19  负载57
  S1买: O需=56 H需=2 F需=5
  买后: O=64 H=32 F=24 负载=120 ✓
  成本: 56×2+2×1+5×2=124  M=240-124=116
```

**结论**：B→S1→E 是全雷暴唯一可作业量 0 但 Z=100 的路径，B-stop 一天使负载合规，M=116。

#### 2.3 为何无作业

绕经 W2 多 2 格（O=+16）→ S1 补给后负载超 120；绕经 W3 多 6 格（O=+48）→ 更不可行。全雷暴下载重上限 120 是绝对瓶颈。

---

### 3. 数学模型

#### 3.1 天气参数化转移方程

消耗参数 C^w(action), w∈{0,1}。对路径骨架第 i 段：

```
O_i = O_{i-1} - d_i·CM_O^w - w1_i·CW_O^w - b_i·CS_O^w - w2_i·CW_O^w + buyO_i
H_i = H_{i-1} - d_i·CM_H^w - w1_i·CW_H^w - b_i·CS_H^w - w2_i·CW_H^w + buyH_i
F_i = F_{i-1} - d_i·CM_F^w - w1_i·CW_F^w - b_i·CS_F^w - w2_i·CW_F^w + buyF_i
M_i = M_{i-1} - (2·buyO_i + 1·buyH_i + 2·buyF_i)
```

#### 3.2 极端雷暴（w=1 恒定）+ B-stop 预处理

B-stop 不是路径骨架的一部分。预处理：试 n_stop=0,1,2 天 B 停泊 → 调整初始资源 (O-3n, H-3n, F-2n) 和可用天数 (30-n) → 对每个 n_stop 运行骨架全枚举 MILP → 取最优。

MILP 约束（与问题一结构相同，仅消耗系数和初始值不同）：

- O_i, H_i, F_i, M_i ≥ 0；O_i+H_i+F_i ≤ 120
- Σ(d_i + w1_j + b_j + w2_j) ≤ 30-n_stop
- w1_j ≤ WM_j, w2_j ≤ WM_j, w2_j ≤ b_j·WM_j

目标：阶段1 max Z → 阶段2 max M。

骨架枚举：Σ 5^k (k=0..8) = 488,281 条，n_stop=0,1,2 → 最多 3×488,281 ≈ 1.5M 次内层求解。

#### 3.3 一般可观测情形：滚动时域（RH-MILP）

每日流程：
1. 观测 w_t
2. 从当前状态求解确定性 MILP（假设未来全雷暴 → 最坏情况保证可行性）
3. 执行 Day-1 行动
4. 按实际天气结算消耗

**adaptive_decision** 核心逻辑：
- 在 B 且 day1 且雷暴：检查 B-stop 是否改善负载平衡（停一天后 S1 补给能否合规）
- 在作业点：若资源足够（雷暴消耗下仍能到 E）且连作未满 → 作业；若连作已满 → 停泊重置
- 其他：移向最近有用目标（补给站优先于作业点优先于 E）

---

### 4. 核心论证

#### 4.1 B-stop 的最优性

B-stop 烧掉 (3,3,2) 资源，以 1 天时间为代价，使 H 从 33→30，S1 补给后负载恰好 120。对比绕 S2 方案（M=77），直达方案节省 4 格移动（O=32），多保留 M=39。B-stop 1 天换 39 M，无人能拒绝。

#### 4.2 滚动时域的 Maximin 最优性

每步假设未来全雷暴（消耗上界），因此：
- 可行性：任意实际天气消耗 ≤ 全雷暴消耗 → 资源约束永远满足
- 最优性：正常天气产生的资源盈余在次日重规划中自动重新分配 → 路径自适应改变（如绕去作业点）

#### 4.3 全雷暴无作业的结构性证明

经过所有 5 个中间点可能路径的最短移动距离分析：
- B→S1→W2→S2→E：15 格，O=120，载重全被油占满，无法再载作业消耗
- B→S1→W3→S2→E：19 格，O=152 > 120，不可行

任意含工作点的路径均需多走 ≥ 2 格（O≥+16），载重约束使其不可行。Z=100 是全雷暴的理论上界。

### 5. 求解方法与结果

#### 5.1 算法流程

```
solve_all_storm:
  for n_stop_B = 0:2
    调整初始 O,H,F,天数
    for k = 0:max_seq
      for 每个长度 k 的骨架
        过滤（重复、超天数、理论上界剪枝）
        贪婪可行性检查 + MILP 两阶段求解
        更新 best
```

#### 5.2 预期结果

| 情形 | Z | M | 说明 |
|------|:--:|:--:|------|
| 全雷暴（极端） | 100 | 116 | B-stop→S1→E，13天 |
| 全正常（最优） | >100 | ≥116 | 可绕作业点，Z 上升 |
| 混合天气 | 100~最优 | 变化 | 取决于正常天数 |
