# 问题二：考虑当日天气可观测条件下的策略设计

## 一、问题分析

问题二在问题一的基础上引入天气影响：

- **正常天气**：消耗同问题一（移动 O=2,H=3,F=2；停泊 O=1,H=1,F=1；作业 O=5,H=4,F=3）
- **雷暴天气**：移动 O=8,H=4,F=3；停泊 O=3,H=3,F=2；作业 O=8,H=6,F=6

**核心约束**：船舶每日行动前仅能观测当日天气，无法预知未来天气。

问题二的特别要求：**以连续30天均为雷暴天气的极端天气下，给出最优航行方案**。

## 二、策略框架设计

### 2.1 决策模型

设 t 日为船舶所在位置 p_t、资源状态 s_t = (O_t, H_t, F_t, M_t, Z_t)、连续作业计数器 c_t、当日天气 w_t ∈ {正常, 雷暴}。

行动空间 A = {上移, 下移, 左移, 右移, 停泊, 作业, 补给(仅在补给点时可行)}。

**贪心-保守混合策略**：由于无法预知未来天气，采取以下原则：

1. **移动优先**：尽可能向目标推进，选择可达性最优的路径
2. **补给保守**：在补给点采购时，按"足够到达下一个补给点 + 合理缓冲"的原则采购，避免过度采购占用载重
3. **作业权衡**：雷暴日作业收益/损耗比显著恶化（正常日作业 O=5→Z=20/15/28 vs 雷暴日 O=8→Z=20/15/28），雷暴日应优先选择移动或停泊
4. **极端预案**：以全雷暴极端情况作为最坏情况基准线设计补给策略

### 2.2 极端情况（全雷暴30天）

在全雷暴天气下，问题退化为确定性规划问题，可使用与问题一相同的列生成框架求解，仅消耗率参数不同。

**关键约束分析**：

| 约束项 | 正常天气 | 雷暴天气 | 影响 |
|--------|:------:|:------:|------|
| 移动燃油消耗 | O=2/格 | O=8/格 | **4倍** |
| 作业燃油消耗 | O=5/天 | O=8/天 | 1.6倍 |
| 停泊燃油消耗 | O=1/天 | O=3/天 | 3倍 |
| 初始燃油 | O=35 | O=35 | 仅够4格移动 |
| 载重上限 | 120 | 120 | 不变 |

**不可行性证明**：

- B→S1 最短距离 = 3格，消耗 O=24，剩余 O=11
- 从 S1 出发，任何作业点至少需要 4格（S1→W1）往返共 8格，O需求 = 8×8 = 64
- 即使考虑在 S1 补给，载重约束下仅能为 O 腾出约 55 单位空间（H+F 已占 ~65）
- 64 > 55 + 11 = 66 → 可容纳。但还需考虑 H/F 需求（H需32, F需24）
- 初始 H=33, F=21，H已满足但F差3单位。总采购 53+3=56 > 55 → **载重超限1单位**
- 通过提前停泊1天消耗 H=3,F=2 可为 O 腾出更多空间，但会导致 H 不足
- 即使勉强完成往返，剩余资金不足以支撑后续 S1→S2→E 航段

**结论**：全雷暴下任何含作业的方案均不可行。

## 三、极端情况最优解

| 指标 | 值 |
|------|:--:|
| 最优 Z | **100** |
| 最优 M | 77 |
| 路径 | B → S1 → S2 → E |
| 旅行天数 | 13天 |
| 作业天数 | 0天 |
| 停泊天数 | 0天 |
| 生成列数 | 0（种子列即最优） |
| 定价迭代 | 1 |

### 每日日志

```
Day  1: B(1,5)→(2,5)  向东移动 (雷暴) O=27 H=41 F=27
Day  2: (2,5)→(3,5)   向东移动 (雷暴) O=19 H=37 F=24
Day  3: (3,5)→(3,4)   向南移动，到达 S1 采购 O:37 H:0 F:0
     采购后: O=48 H=33 F=21 载重=102 资金=166
Day  4-8: S1→S2 (5天东移+1天北移)
Day  9: 到达 S2(7,6)，采购 O:32 H:7 F:9
     采购后: O=32 H=16 F=12 载重=60 资金=77
Day 10-12: S2→E (2天东移+2天南移)
Day 13: 到达 E(10,5)，O=0 H=0 F=0 M=77 Z=100
```

## 四、方法评价

**优点**：
- 极端情况退化为确定性规划，可用列生成精确求解
- 策略框架兼顾日常决策灵活性和极端情况鲁棒性
- 补给保守策略避免在不知未来天气时过度消耗资金

**局限**：
- 全雷暴下 Z=100 无提升空间，天气不确定性对方案质量影响巨大
- 混合天气下的最优策略需要更复杂的随机规划或强化学习方法
- 当前决策策略未考虑天气概率信息（将在问题三中加入）
