# 问题三 解法说明

## 问题概述

30×30 网格海域，B(1,15) → E(30,15)，90 天期限。
每日天气独立同分布：P(正常)=0.8，P(雷暴)=0.2。
船舶每日只能观测当日天气，不可预知未来，但可利用概率先验优化策略。

**目标**：字典序优化 max Z，同 Z 时 max M。

### 关键参数

| 参数 | 值 |
|------|-----|
| 载重上限 | 400 |
| 初始 (O,H,F,M,Z) | (100,150,100,750,200) |
| 补给点 | S1(12,16), S2(21,16) |
| 作业点 | W1(6,21,20/天,max4), W2(15,9,15/天,max5), W3(24,24,28/天,max3) |
| 补给价格 | O=2, H=1, F=2 |

---

## 数学模型

### 符号定义

```
t          ∈ {1,...,90}                      天数
s_t        = (x_t, y_t, O_t, H_t, F_t, M_t, Z_t, j_t)  第 t 天状态
w_t        ∈ {Normal, Storm}                  第 t 天天气
a_t        ∈ {Move, Work, Moor, Supply}       第 t 天动作
V_t(s,w)                                      状态-动作价值函数
```

### 资源约束

```
O_i + H_i + F_i ≤ 400           ∀i          载重约束
O_i, H_i, F_i, M_i, Z_i ≥ 0    ∀i          非负约束
j_τ ≤ WM(k)                     ∀τ         连续作业上限
```

### 资源平衡方程

移动(1格)：
```
O_{i+1} = O_i - CM(w)_O
H_{i+1} = H_i - CM(w)_H
F_{i+1} = F_i - CM(w)_F
```

作业(1天)：
```
O_{i+1} = O_i - CW(w)_O
H_{i+1} = H_i - CW(w)_H
F_{i+1} = F_i - CW(w)_F
Z_{i+1} = Z_i + WY(k)
j_{i+1} = j_i + 1
```

补给(1天)：
```
O_{i+1} = O_i - CS(w)_O + buy_O
H_{i+1} = H_i - CS(w)_H + buy_H
F_{i+1} = F_i - CS(w)_F + buy_F
M_{i+1} = M_i - (2·buy_O + buy_H + 2·buy_F)
j_{i+1} = 0
```

其中：
```
CM(Normal) = [2,3,2],  CM(Storm) = [8,4,3]
CW(Normal) = [5,4,3],  CW(Storm) = [8,6,6]
CS(Normal) = [1,1,1],  CS(Storm) = [3,3,2]
WY = [20,15,28],       WM = [4,5,3]
```

### 随机动态规划

```
V_t(s, w) = max_{a∈A(s,w)} { Z增益 + E_{w'"'"'}[V_{t+1}(s'"'"', w'"'"')] }

其中 E_{w'"'"'}[·] = 0.8·V_{t+1}(·|Normal) + 0.2·V_{t+1}(·|Storm)
```

## 算法架构：四阶段递进

```
Phase 1: 骨架枚举 + 贪婪评估
Phase 2: 两阶段 MILP 优化
Phase 3: SAA 场景评估（500 天气序列）
Phase 4: 每日滚动时域重解
```

### Phase 1: 骨架枚举

枚举所有从 B 到 E 经过中间 POI 的拓扑可行路径。

```
B → [W1/W2/W3/S1/S2]* → E
```

最多 4 个中间点，5^0+...+5^4 = 781 条候选路径。
剪枝规则：
- 重复 POI 跳过
- 总行程 > 80 天跳过
- 贪婪资源预检失败跳过

**输出**：前 10 个最优骨架（按两阶段 MILP 排序）

### Phase 2: 两阶段 MILP

对每个骨架求解资源最优分配。

**第一阶段**（max Z）：
```
目标：max  Z = IZ + Σ(WY(k)·(w1_k + w2_k))
约束：资源平衡、载重 400、天数 ≤ 90、WM 上限
变量：w1_k, b_k, w2_k ∈ ℤ, buy_O, buy_H, buy_F ∈ ℤ
```

**第二阶段**（fix Z, max M）：
```
目标：max  M_final
约束：Z = Z*（第一阶段最优值）+ 所有第一阶段约束
```

### Phase 3: SAA 评估

对 Phase 2 选出的 top 10 骨架，每个用 500 个随机天气序列模拟评估。

```
for s = 1 to 500:
  生成天气序列 ω_s ~ Bernoulli(0.2)
  在 ω_s 下执行骨架，记录 Z_s
Z_sum += Z_s  （失败场景 Z_s = 0）
```

**选优准则**：E[Z] = Z_sum / 500（包含失败场景）

### Phase 4: 每日滚动时域

```
for day = 1 to 90:
  w = wx(day)                   观测今日天气
  if 到达决策点(POI):
    根据当前资源 + 期望消耗重新优化剩余路径
    执行第一个动作
  else:
    移向下一个 POI（用 w 计算当日消耗）
```

**核心机制**：每天观测当天实际天气，用**期望消耗**规划剩余路程。这和 Task 2 的 persistence forecast 不同——Task 3 已知概率，可以用更准确的期望值。

---

## 自适应补给策略

在补给点 S1/S2，按**骨架剩余路径**计算采购量（非直线距离）：

```
rd = 剩余行程(格) × CMe_O + 剩余作业(天) × CWe_O
安全缓冲 = 0.5 × √((rd + rw) × VM_O)
buy_O = max(0, rd + 安全缓冲 - 当前 O)
```

受资金约束：if cost > M, 按比例缩减。

## 结果

### 最优骨架

```
B → S1 → S2 → W3 → E
```

| 指标 | 值 |
|------|-----|
| 抵达日 | 56 天 |
| 最终 Z | 368 |
| 最终 M | 320 |
| W3 作业 | 6 天（3+停泊+3） |
| 成功率 | 96% (478/500) |
| 期望 Z | 355 |

### Z—成功率权衡

| 路径 | 理论 Z | 成功率 | 期望 Z |
|------|--------|--------|--------|
| B→S1→W2→S2→W3→E | 518 | 28% | 147 |
| B→S1→S2→W3→E | **368** | **96%** | **355** |
| B→S1→W3→E | 368 | 52% | 190 |

加入额外作业点（W1/W2）后，Storm 天气下资源消耗激增，成功率断崖式下降，期望 Z 反而更低。
