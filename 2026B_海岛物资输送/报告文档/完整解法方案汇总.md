## 一、题目总览

### 1.1 问题背景

某海岛遭遇自然灾害，需从起点 B 向终点 E 输送目标物资 Z。船舶在 10×10（任务1、2）或 30×30（任务3）的网格海面上航行，途经补给点 S1、S2 采购燃油(O)、淡水(H)、食物(F)，访问作业点 W1、W2、W3 开展作业获取 Z 收益。船舶受**载重上限**、**连续作业上限**、**时间窗**、**资金预算**等多重约束。

### 1.2 三任务参数汇总

| 参数 | 任务1 | 任务2（极端） | 任务3 |
|------|:---:|:---:|:---:|
| 网格规模 | 10×10 | 10×10 | 30×30 |
| 时限 T | 30天 | 30天 | 90天 |
| 初始 (O, H, F) | (35, 45, 30) | (35, 45, 30) | (100, 150, 100) |
| 初始 M / Z | 240 / 100 | 240 / 100 | 750 / 200 |
| 载重上限 | 120 | 120 | 400 |
| 天气 | 全正常（确定） | 全雷暴（确定） | P(正常)=0.8, P(雷暴)=0.2 |
| 决策模型 | 离线全局优化 | 在线逐日决策 | 在线期望值决策 |

### 1.3 消耗参数

### 1.6 共用方法框架：约束规划 (CP)

三个任务统一使用**约束规划**框架求解，核心机制为：

- **值域缩减**：根据资源余量删除不可行的下一目标点
- **约束传播**：动作后自动检查资源非负和载重上限，违规分支终止
- **分支**：在"路径骨架"层面递归尝试中间点（W1,W2,W3,S1,S2）
- **回溯 + 剪枝**：上界剪枝、前向检查、相邻去重三条规则

三任务仅在**消耗参数层**做适配，核心搜索结构完全一致。

## 二、任务1：正常天气下的最优航行方案

### 2.1 问题建模

#### 2.1.1 决策变量

- **路径骨架**：有序序列 P = (B, p_1, p_2, ..., p_k, E)，p_i ∈ {W1, W2, W3, S1, S2}
- **工作天数**：每个作业点 p_j 的工作天数 w_j ∈ ℤ_+
- **停泊天数**：每个工作点若 w_j > WM_i，需插入 ceil(w_j/WM_i) − 1 个停泊日分隔作业会话

#### 2.1.2 约束

(1) **载重约束**：∀t, O_t + H_t + F_t ≤ 120
(2) **非负约束**：∀t, O_t ≥ 0, H_t ≥ 0, F_t ≥ 0
(3) **连续作业上限**：单次连续作业 ≤ WM_i（W1=4, W2=5, W3=3）
(4) **时间窗约束**：总旅行天数 + 总停留天数 ≤ 30
(5) **资金约束**：补给日采购花费 ≤ 当前 M

#### 2.1.3 目标函数（词典序）

**max Z**，其次 **max M**，其中 Z 和 M 为抵达 E 时的值。

### 2.2 约束规划搜索策略

#### 2.2.1 路径骨架搜索

采用递归深度优先，从 B 出发依次访问中间点。每个搜索节点尝试 {W1, W2, W3, S1, S2} 中的可行选项。路径到达叶节点（以 E 结尾）后进行工作天数+停泊天数的组合枚举。

#### 2.2.2 三条剪枝规则

**规则1 — 上界剪枝**：

在搜索树任意节点 (pos, t)，最乐观假设剩余天数全部在 W3（收益 28/天）作业，并考虑连续作业上限所需的停泊日。剩余最大收益：

```
UB_Z = 100 + max_work_with_park(WM=3, remaining = 30 − t − dist(pos, E)) × 28
```

若 UB_Z ≤ best_Z，整棵子树被剪掉。

`max_work_with_park(mc, R)` 计算在 R 天内（含必要停泊日）最多可作业天数：

$$maxWork = \max_{k \ge 1} \left\{ k \cdot mc \mid k \cdot mc + (k-1) \le R \right\}$$

并利用剩余松弛 min(mc, slack−1) 追加部分工作日。

**规则2 — 相邻去重**：跳过与当前位置相同的点（距离为 0 的无意义重复）。

**规则3 — 前向检查**：添加点 p 前验证 tsf + dist(current, p) + dist(p, E) ≤ 30。不满足则 p 无法在时限内抵达 E。

#### 2.2.3 停泊−再作业策略

问题允许船舶在作业点选择停泊（不作业，消耗 O=1,H=1,F=1/天），停泊日后连续作业计数器归零，可开始新一轮连续作业。这远比"离开作业点→访问补给点→返回"节省天数。

**示例**（W3, WM=3，需工作 6 天）：
- 旧方案：访问 W3 两次，中间绕行 S2，纯旅行 6 天，总停留 12 天
- 新方案：一次访问（作业 3 + 停泊 1 + 作业 3），停留 7 天
- **节省 5 天**

#### 2.2.4 核心模拟函数 gsim()

gsim 是叶节点评估的核心：给定路径骨架和工作/停泊天数组，逐日模拟资源消耗、Z 累加和补给决策。

**补给日采购算法**：
1. 找下一补给日 ns
2. 计算从当前日 t+1 到 ns 所需的总资源 (nO, nH, nF)，**含 ns 到达日的消耗**
3. 采购量 = max(0, 需求 − 当前余量)，受剩余载重空间限制

**⚠ 关键 Bug 修复**：补给日消耗扣除必须在采购**之前**执行。原代码先执行采购再扣除到达日消耗，导致补给日消耗未被计入到达资源需求，M 虚高（从 44 修正为 21）。

### 2.4 论证

**最优性保证**：CP 搜索探索了所有可能的路径骨架（B→中间点→E 的排列组合，受前向检查约束）。对每个骨架枚举了所有 (<30 天) 的工作天数+停泊天数组合。上界剪枝仅移除可证明不优的分支（ UB_Z ≤ best_Z 意味着该子树不可能产生更优解）。搜索树完备——所有可行解均被评估。

**验证**：通过诊断工具直接调用 `sim()` 验证特定方案，输出 `Z=328, M=21`，与 CP 搜索结果一致。

```matlab
function [bZ,bM,bP,bW,bWD,bSched,nodes]=cp_search(path,tsf,wa,ww,bZ,bM,bP,bW,bWD,bSched,dist,inter_idx,WY,WM,nodes,depth,MAX_DAYS,MAX_LOAD)
    nodes=nodes+1; lp=path(end);
    if lp~=2
        dE=dist(lp,2); rem=MAX_DAYS-tsf;
        if rem<dE, return; end
        ub=100+max_work_with_park(3,rem-dE)*28;
        if ub<=bZ && bZ>-inf, return; end
    end
    dE=dist(lp,2);
    if tsf+dE<=MAX_DAYS
        fp=[path,2]; m=length(fp)-2; tt=0;
        for k=1:m+1, tt=tt+dist(fp(k),fp(k+1)); end
        rem=MAX_DAYS-tt; nw=length(wa);
        if nw==0
            [ok,Z,M,sched]=gsim(fp,m,dist,wa,ww,tt,[],WM,WY,MAX_LOAD);
            if ok && (Z>bZ || (Z==bZ && M>bM))
                bZ=Z; bM=M; bP=fp; bW=0; bWD=[]; bSched=sched;
            end
        else
            max_wk=zeros(1,nw);
            for j=1:nw, max_wk(j)=max_work_with_park(WM(ww(j)),rem); end
            sz=max_wk+1; nc=prod(sz);
            for ci=1:nc
                wd=zeros(1,nw); t2=ci-1;
                for j=nw:-1:1, wd(j)=mod(t2,sz(j)); t2=floor(t2/sz(j)); end
                total_stay=0;
                for j=1:nw
                    if wd(j)>0, total_stay=total_stay+wd(j)+max(0,ceil(wd(j)/WM(ww(j)))-1); end
                end
                if tt+total_stay>MAX_DAYS, continue; end
                [ok,Z,M,sched]=gsim(fp,m,dist,wa,ww,tt,wd,WM,WY,MAX_LOAD);
                if ok && (Z>bZ || (Z==bZ && M>bM))
                    bZ=Z; bM=M; bP=fp; bW=total_stay; bWD=wd; bSched=sched;
                end
            end
        end
    end
    for ni=1:5, np=inter_idx(ni);
        if np==lp, continue; end
        d=dist(lp,np); if tsf+d>MAX_DAYS, continue; end
        dE2=dist(np,2); if tsf+d+dE2>MAX_DAYS, continue; end
        np2=[path,np]; nt=tsf+d; nwa=wa; nww=ww;
        if np>=3 && np<=5, nwa(end+1)=length(np2); nww(end+1)=np-2; end
        [bZ,bM,bP,bW,bWD,bSched,nodes]=cp_search(np2,nt,nwa,nww,bZ,bM,bP,bW,bWD,bSched,dist,inter_idx,WY,WM,nodes,depth+1,MAX_DAYS,MAX_LOAD);
    end
end

function [f,Zf,Mf,sched]=gsim(pid,m,dist_all,wa,ww,tt,wdays,WM,WY,MAX_LOAD)
total_extra=0;
for j=1:length(wdays)
    if wdays(j)>0, total_extra=total_extra+max(0,ceil(wdays(j)/WM(ww(j)))-1); end
end
T=tt+sum(wdays)+total_extra;
cO=zeros(1,T); cH=zeros(1,T); cF=zeros(1,T); zG=zeros(1,T); isSup=false(1,T);
day=0;
for k=1:m+1
    d=dist_all(pid(k),pid(k+1));
    for dd=1:d
        day=day+1; cO(day)=2; cH(day)=3; cF(day)=2;
        if dd==d, to_pt=pid(k+1); if to_pt==6||to_pt==7, isSup(day)=true; end; end
    end
    if ~isempty(wa)
        wk=find(wa==k+1,1);
        if ~isempty(wk) && wdays(wk)>0
            mc=WM(ww(wk)); rem=wdays(wk); yld=WY(ww(wk));
            while rem>0
                chunk=min(rem,mc);
                for w=1:chunk, day=day+1; cO(day)=5; cH(day)=4; cF(day)=3; zG(day)=yld; end
                rem=rem-chunk;
                if rem>0, day=day+1; cO(day)=1; cH(day)=1; cF(day)=1; zG(day)=0; end
            end
        end
    end
end
O=35; H=45; F=30; M=240; Zf=100; f=false; Mf=0; sched=struct();
for t=1:T
    % FIXED: deduct consumption FIRST (even at supply points)
    O=O-cO(t); H=H-cH(t); F=F-cF(t); Zf=Zf+zG(t);
    if O<0||H<0||F<0, f=false; return; end
    if O+H+F>MAX_LOAD+1e-9, f=false; return; end
    if isSup(t)
        ns=T+1; for tt2=t+1:T, if isSup(tt2), ns=tt2; break; end; end
        nO=0; nH=0; nF=0; for tt2=t+1:ns, if tt2>T, break; end; nO=nO+cO(tt2); nH=nH+cH(tt2); nF=nF+cF(tt2); end
        sp=MAX_LOAD-(O+H+F); bO=max(0,nO-O); bH=max(0,nH-H); bF=max(0,nF-F);
        if bO+bH+bF>sp, f=false; return; end
        if ns>T && (O+bO<nO||H+bH<nH||F+bF<nF), f=false; return; end
        cost=bO*2+bH*1+bF*2; if cost>M, f=false; return; end
        O=O+bO; H=H+bH; F=F+bF; M=M-cost;
    end
end
f=true; Mf=M;
sched=struct();
end

function max_w=max_work_with_park(mc,remaining)
best=0;
for k=1:(remaining+1)
    stay=k*mc+(k-1);
    if stay>remaining, break; end
    best=k*mc;
    slack=remaining-stay;
    if slack>=1, best=max(best,k*mc+min(mc,slack-1)); end
end
max_w=max(best,min(mc,remaining));
end

            fprintf('%3d | (%2d,%2d)     | move        | %3d %3d %3d %4d | %4d %5d\n',day2,x,y,O,H,F,O+H+F,Z,M);
        end
    end
    wk=find(wa==k+1,1);
    if ~isempty(wk) && bWD(wk)>0
        mc=WM(ww(wk)); rem=bWD(wk); yld=WY(ww(wk));
        while rem>0
            chunk=min(rem,mc);
            for w=1:chunk
                day2=day2+1; O=O-5; H=H-4; F=F-3; Z=Z+yld;
                fprintf('%3d | (%2d,%2d)     | work(%s)    | %3d %3d %3d %4d | %4d %5d\n',day2,all_xy(to,1),all_xy(to,2),names{to},O,H,F,O+H+F,Z,M);
            end
            rem=rem-chunk;
            if rem>0
                day2=day2+1; O=O-1; H=H-1; F=F-1;
                fprintf('%3d | (%2d,%2d)     | park(reset) | %3d %3d %3d %4d | %4d %5d\n',day2,all_xy(to,1),all_xy(to,2),O,H,F,O+H+F,Z,M);
            end
        end
    end
end
fprintf('----|-------------|-------------|------------------|------------\n');
fprintf('  Final at E: Z=%d M=%d Day=%d\n',Z,M,day2);
end
```

## 三、任务2：雷暴极端天气在线决策模型

### 3.1 问题转化与分析

任务2要求在**30 天全为雷暴**的极端天气下给出最优航行方案。雷暴下消耗参数变为：

| 动作 | O | H | F |
|------|:---:|:---:|:---:|
| 移动（每格） | 8 | 4 | 3 |
| 停泊（每天） | 3 | 3 | 2 |
| 作业（每天） | 8 | 6 | 6 |

#### 3.1.1 连通性分析

```
B → S1: 3格, O_need = 24 ≤ 35 ✓  (可达)
B → S2: 7格, O_need = 56 > 35 ✗  (不可达)
B → W1: 3格, O_need = 24 ≤ 35 ✓  (可达)
B → W2: 6格, O_need = 48 > 35 ✗  (不可达)
B → W3: 10格, O_need = 80 > 35 ✗ (不可达)
```

从 B 出发仅 S1 和 W1 可达。S2、W2、W3 均无法直接到达。

#### 3.1.2 载重瓶颈分析

直接 B → S1 → E 路径：

- B → S1 (3 格)：消耗 O = 24，到达 S1 时 O=11, H=33, F=21，负载 = 65，剩余载重空间 = 55
- S1 → E (8 格) 需采购：O = 64 − 11 = 53, H = max(0, 32 − 33) = 0, F = 24 − 21 = 3，合计 56
- **56 > 55**，超出载重上限 1 单位！

#### 3.1.3 瓶颈突破：海上停泊策略

雷暴天气下，停泊作为一种**消耗资源、腾出采购空间**的手段：在到达 S1 前在海上停泊 p 天，每天消耗 O=3, H=3, F=2，降低总负载，为补给采购腾出空间。

| p | 到达 S1 负载 | 剩余空间 | 采购需求 | 可行？ | M 剩余 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | 65 | 55 | 56 | ✗ | — |
| **1** | **57** | **63** | **63** | **✓** | **116** |
| 2 | 49 | 71 | 71 | ✓ | 103 |
| 3 | 41 | 79 | 79 | ✓ | 90 |

最优：**p = 1 天，M = 116**。

#### 3.1.4 作业不可行证明

从 S1 出发尝试任一作业点再前往 E：

```
S1 → W1 → E: O_travel = 4×8 + 10×8 = 112 > 71 (S1最大可购O)
S1 → W2 → E: O_travel = 3×8 + 7×8 = 80 > 71
S1 → W3 → E: O_travel = 9×8 + 5×8 = 112 > 71
```

在 S1 可购买的最大 O = 8（到达 S1 时余量）+ 63（全空间）= 71。任何含作业的路径均 O_travel > 71，不可行。

### 3.2 在线决策数学模型

#### 3.2.1 状态空间

$$S_t = (x_t, y_t,\; O_t, H_t, F_t,\; M_t,\; Z_t,\; c_t,\; w_t,\; d_t)$$

| 符号 | 含义 | 约束 |
|------|------|------|
| (x_t, y_t) | 网格坐标 | {1,…,10}² |
| O_t, H_t, F_t | 资源余量 | O+H+F ≤ 120 |
| M_t | 资金 | ℤ_{≥0} |
| Z_t | 目标物资 | ℤ_{≥0} |
| c_t | 连续作业天数 | 0 ≤ c_t ≤ WM_i |
| w_t | 当日天气（观测值） | {正常, 雷暴} |
| d_t | 天数 | 1,…,30 |

#### 3.2.2 决策架构

```
逐日循环 (t = 1, 2, ..., 30):
  ├─ 观测: w_t ← 当日天气
  ├─ CP搜索: 从 S_t 出发，假设剩余天气 = w_t
  │          搜索最优路径骨架 + 工作/停泊组合
  ├─ 执行: 路径骨架的首个动作
  └─ 状态转移: S_{t+1} = T(S_t, a_t^*, w_t)
```

**天气假设策略**：CP 搜索假设剩余天数天气与今日相同（悲观且一致）。全雷暴情形下假设与真实一致 → 等价确定性全局最优。

### 3.3 最优解

| 指标 | 值 |
|------|:---:|
| **Z** | **100**（无法开展作业） |
| **M** | **116** |
| 路径 | B → 停泊 1 天 → S1（补给）→ E |
| 旅行距离 | 11 格（3+8） |
| 总天数 | 12 天（剩余 18 天裕量） |
| CP 探索节点 | ≈200 |

##### 逐日明细

| 日期 | 位置 | 动作 | O | H | F | 负载 | Z | M |
|:---:|------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 1 | (1, 5) | 停泊 | 32 | 42 | 28 | 102 | 100 | 240 |
| 2 | (2, 5) | 移动 | 24 | 38 | 25 | 87 | 100 | 240 |
| 3 | (3, 5) | 移动 | 16 | 34 | 22 | 72 | 100 | 240 |
| 4 | (3, 4) | 补给 S1 | 64 | 32 | 24 | 120 | 100 | 116 |
| 5−11 | →E | 移动×7 | ↘ | ↘ | ↘ | ↘ | 100 | 116 |
| 12 | (10, 5) | 抵达 E | 0 | 0 | 0 | 0 | 100 | 116 |

**补给明细**：S1 采购 O=56, H=2, F=5，花费 56×2+2×1+5×2 = **124**，剩余 M = 240−124 = **116**。

### 3.4 与任务1的对比

| 维度 | 任务1 (正常天气) | 任务2 (雷暴极端) |
|------|:---:|:---:|
| Z | 328 | **100** |
| M | 21 | **116** |
| 关键瓶颈 | 连续作业上限 (WM) | **载重上限 (120)** |
| 停泊作用 | 重置连续作业计数器 | **消耗资源、腾出采购空间** |
| 工作天数 | 9 天 | **0 天** |
| 最优策略类型 | 最大化作业收益 | **最小化航行距离** |

雷暴天气下燃油消耗翻 4 倍，载重上限成为绝对瓶颈。最优策略从"最大化作业收益"变为"最小化航行距离以存活到达 E"。

### 3.5 论证

**完备性**：CP 搜索探索了所有可能的路径骨架（B→{W1,S1}的排列，S2/W2/W3 因不可达被值域缩减删除）。对每个骨架枚举了海上停泊天的全部可行组合。

**工作不可行**：穷举验证了所有含 W1/W2/W3 的路径 —— 任一含作业点的绕行距离所需 O 均 > S1 能采购的最大 O(71)，所有含作业路径均在 sim() 中返回不可行。

**最优性**：上界剪枝在搜索树非叶节点排除了不可能超越 best_Z 的子树。全雷暴下 Z 恒为 100（无作业可行），优化退化为 max M。p=1 在所有可行 p 中使 M 最大。

### 3.6 在线决策特性说明

任务2 的在线 CP 框架**同时支持**：
- **全雷暴极端**：每日观测到雷暴 → CP 假设剩余全雷暴 → 等价确定性规划
- **混合天气**：每日重新观测 → CP 重新规划 → 自适应调整

在线框架使模型在任务2 给定的极端特例之外，也具备处理混合天气序列的能力，为任务3 铺平道路。

```matlab

function [bZ, bM, bP, bWD, bPS, bSched, nodes] = cp_search_q2(...
    path, tsf, wa, ww, bZ, bM, bP, bWD, bPS, bSched, ...
    dist, inter_idx, WY, WM, cons, nodes, depth, MAX_DAYS, MAX_LOAD, ...
    INIT_O, INIT_H, INIT_F, INIT_M, INIT_Z)

    nodes = nodes + 1;
    lp = path(end);

    if lp ~= 2
        dE = dist(lp, 2);
        rem = MAX_DAYS - tsf;
        if rem < dE
            return;
        end
        max_w = max_work_with_park(3, rem - dE);
        ub = INIT_Z + real(max_w) * 28;
        if ub <= bZ && bZ > -inf
            return;
        end
    end

    dE = dist(lp, 2);
    if tsf + dE <= MAX_DAYS
        fp = [path, 2];
        m = length(fp) - 2;
        tt = 0;
        for k = 1:(m+1)
            tt = tt + dist(fp(k), fp(k+1));
        end
        
        rem_days = MAX_DAYS - tt;
        nw = length(wa);

        if nw == 0
            [bZ, bM, bP, bWD, bPS, bSched] = eval_leaf_no_work(...
                fp, m, tt, rem_days, dist, bZ, bM, bP, bWD, bPS, bSched, ...
                cons, MAX_DAYS, MAX_LOAD, INIT_O, INIT_H, INIT_F, INIT_M, INIT_Z);
        else
            max_wk = zeros(1, nw);
            for j = 1:nw
                max_wk(j) = max_work_with_park(WM(ww(j)), rem_days);
            end
            sz = max_wk + 1;
            nc = prod(sz);
            for ci = 1:nc
                wd = zeros(1, nw);
                t2 = ci - 1;
                for j = nw:-1:1
                    wd(j) = mod(t2, sz(j));
                    t2 = floor(t2 / sz(j));
                end
                total_stay = 0;
                for j = 1:nw
                    if wd(j) > 0
                        total_stay = total_stay + wd(j) + max(0, ceil(wd(j)/WM(ww(j))) - 1);
                    end
                end
                if tt + total_stay > MAX_DAYS
                    continue;
                end
                park_rem = MAX_DAYS - tt - total_stay;
                [bZ, bM, bP, bWD, bPS, bSched] = eval_leaf_with_work_park(...
                    fp, m, tt, wd, park_rem, dist, wa, ww, bZ, bM, bP, bWD, bPS, bSched, ...
                    cons, MAX_DAYS, MAX_LOAD, WM, WY, INIT_O, INIT_H, INIT_F, INIT_M, INIT_Z);
            end
        end
    end

    for ni = 1:5
        np = inter_idx(ni);
        if np == lp
            continue;
        end
        d = dist(lp, np);
        if tsf + d > MAX_DAYS
            continue;
        end
        dE2 = dist(np, 2);
        if tsf + d + dE2 > MAX_DAYS
            continue;
        end
        np2 = [path, np];
        nt = tsf + d;

function combs = enumerate_park_combinations(n_seg, max_total)
    combs = zeros(0, n_seg);
    current = zeros(1, n_seg);
    enumerate_rec(1, max_total);

    function enumerate_rec(pos, remain)
        if pos == n_seg
            current(pos) = remain;
            combs(end+1, :) = current;
            return;
        end
        for p = 0:remain
            current(pos) = p;
            enumerate_rec(pos + 1, remain - p);
        end
    end
end

function [feasible, Zf, Mf, sched] = gsim_q2(pid, m, dist_all, wa, ww, tt, wdays, park_seg, ...
    cons, MAX_LOAD, INIT_O, INIT_H, INIT_F, INIT_M, INIT_Z)

    T_alloc = tt + sum(wdays) + sum(park_seg) + 100;
    cO = zeros(1, T_alloc);
    cH = zeros(1, T_alloc);
    cF = zeros(1, T_alloc);
    zG = zeros(1, T_alloc);
    isSup = false(1, T_alloc);
    
    day = 0;
    
    for k = 1:(m+1)
        d = dist_all(pid(k), pid(k+1));
        % 1. Park at sea BEFORE moving (reduces load before supply point)
        for pd = 1:park_seg(k)
            day = day + 1;
            cO(day) = cons.PO;
            cH(day) = cons.PH;
            cF(day) = cons.PF;
        end
        % 2. Move to destination
        for dd = 1:d
            day = day + 1;
            cO(day) = cons.MO;
            cH(day) = cons.MH;
            cF(day) = cons.MF;
            if dd == d
                to_pt = pid(k+1);
                if to_pt == 6 || to_pt == 7
                    isSup(day) = true;
                end
            end
        end
        % 3. Work (at destination, after supply will trigger on move arrival day)
        wk = find(wa == k+1, 1);
        if ~isempty(wk) && wdays(wk) > 0
            wm_val = 3;
            if ww(wk) == 1, wm_val = 4; end
            if ww(wk) == 2, wm_val = 5; end
            yld = 0;
            if ww(wk) == 1, yld = 20; end
            if ww(wk) == 2, yld = 15; end
            if ww(wk) == 3, yld = 28; end
            
            rem_val = wdays(wk);
            while rem_val > 0
                chunk = min(rem_val, wm_val);
                for w = 1:chunk
                    day = day + 1;
                    cO(day) = cons.WO;
                    cH(day) = cons.WH;
                    cF(day) = cons.WF;
                    zG(day) = yld;
                end
                rem_val = rem_val - chunk;
                if rem_val > 0
                    day = day + 1;
                    cO(day) = cons.PO;
                    cH(day) = cons.PH;
                    cF(day) = cons.PF;
                    zG(day) = 0;
                end
            end
        end
    end
    
    T_actual = day;
    
    O = INIT_O; H = INIT_H; F = INIT_F;
    M = INIT_M; Zf = INIT_Z;
    
    for t = 1:T_actual
        O = O - cO(t);
        H = H - cH(t);
        F = F - cF(t);
        Zf = Zf + zG(t);
        
        if O < 0 || H < 0 || F < 0
            feasible = false; Mf = 0; sched = struct();
            return;
        end
        
        if O + H + F > MAX_LOAD + 1e-9
            feasible = false; Mf = 0; sched = struct();
            return;
        end
        
        if isSup(t)
            ns = T_actual + 1;
            for tt2 = (t+1):T_actual
                if isSup(tt2)
                    ns = tt2;
                    break;
                end
            end
            
            nO = 0; nH = 0; nF = 0;
            for tt2 = (t+1):ns
                if tt2 > T_actual, break; end
                nO = nO + cO(tt2);
                nH = nH + cH(tt2);
                nF = nF + cF(tt2);
            end
            
            sp = MAX_LOAD - (O + H + F);
            bO = max(0, nO - O);
            bH = max(0, nH - H);
            bF = max(0, nF - F);
            
            if bO + bH + bF > sp
                feasible = false; Mf = 0; sched = struct();
                return;
            end
            
            if ns > T_actual && (O + bO < nO || H + bH < nH || F + bF < nF)
                feasible = false; Mf = 0; sched = struct();
                return;
            end
            
            cost = bO * cons.pO + bH * cons.pH + bF * cons.pF;
            if cost > M
                feasible = false; Mf = 0; sched = struct();
                return;
            end
            
            O = O + bO; H = H + bH; F = F + bF;
            M = M - cost;
        end
    end
    
    feasible = true;
    Mf = M;
    sched = struct();
end

function max_w = max_work_with_park(mc, remaining)
    best = 0;
    for k = 1:(remaining + 1)
        stay = k * mc + (k - 1);
        if stay > remaining
            break;
        end
        best = k * mc;
        slack = remaining - stay;
        if slack >= 1
            best = max(best, k * mc + min(mc, slack - 1));
        end
    end
    max_w = max(best, min(mc, remaining));
end

end
```

## 四、任务3：随机天气期望值约束规划模型

### 4.1 问题转化

任务3 将规模扩大到 30×30 网格、90 天时限，且天气服从独立同分布：P(正常) = 0.8, P(雷暴) = 0.2。核心挑战在于**天气随机性**——无法预知未来天气。

**核心策略：期望消耗替代确定消耗。**

### 4.2 期望消耗模型

$$\mathbb{E}[c] = 0.8 \cdot c_{\text{normal}} + 0.2 \cdot c_{\text{thunder}}$$

| 动作 | 期望 O | 期望 H | 期望 F |
|------|:---:|:---:|:---:|
| 移动（每格） | 3.2 | 3.2 | 2.2 |
| 停泊（每天） | 1.4 | 1.4 | 1.2 |
| 作业（每天） | 5.6 | 4.4 | 3.6 |

CP 搜索使用期望消耗替代确定消耗进行路径规划。上界剪枝中融入天气概率的乐观估计。叶节点评估时调用期望值计算。

### 4.3 最优解确定：完整枚举验证

### 4.6 论证

**最优性**：对候选路径 A 和 B，通过完整枚举验证了所有可行的工作天数+停泊天数组合。路径 B (Z=480) 的 Z 严格大于路径 A (Z=452)，且搜索覆盖了所有可能的路径骨架。

**路径 B 优于 A 的原因**：双次 W3 访问利用了 S2 的额外载重空间（400），允许第二次采购后携带更多资源支撑额外工作天。单次 W3 访问受 S1 载重空间（153.2）限制，最多工作 9 天。

### 5.5 向更大规模推广

CP 框架向上扩展策略：

1. **网格扩大**：值域缩减自动处理可达性；前向检查限制搜索深度；距离预计算不变
2. **时限增长**：上界剪枝作用增强（UB_Z 在更大剩余时间中更准确地排除劣解）
3. **天气随机化**：期望消耗模型平滑天气不确定性；在线重规划适配逐日天气观测
4. **多点位**：分支因子增长，但上界剪枝 + 前向检查有效控制搜索树规模

限制因素：
- 递归深度（MATLAB 默认 500），超大规模需转迭代或增加递归限制
- 叶节点枚举组合数随作业点增多指数膨胀，需引入更强的束搜索或启发式剪枝

## 六、在线决策模型详解与工程实现

### 6.1 完整的在线决策数学模型

以下模型是从任务2在线决策需求中提炼的独立数学模型，完整描述"根据当前状态实时制定当日动作"的决策过程。

#### 6.1.1 状态空间

$$S_t = (pt,\; O_t,\; H_t,\; F_t,\; M_t,\; Z_t,\; c_t,\; w_t,\; d_t)$$

| 符号 | 含义 | 值域 |
|------|------|------|
| $pt$ | 当前所在点位 | {1=B, 2=E, 3=W1, 4=W2, 5=W3, 6=S1, 7=S2} |
| $O_t, H_t, F_t$ | 燃油、淡水、食物余量 | $\mathbb{Z}_{\ge 0}$, $O+H+F \le 120$ |
| $M_t$ | 剩余资金 | $\mathbb{Z}_{\ge 0}$ |
| $Z_t$ | 目标物资存量 | $\mathbb{Z}_{\ge 0}$ |
| $c_t$ | 连续作业天数 | $[0, WM_i]$ |
| $w_t$ | 当日天气（观测值） | {N(正常), T(雷暴)} |
| $d_t$ | 当前天数 | {1,...,30} |

#### 6.1.2 动作空间

$$A(S_t) = \{\uparrow, \downarrow, \leftarrow, \rightarrow, \text{停泊}, \text{作业}, \text{补给}\}$$

动作可行性受四重约束过滤：
- 移动：需 $O_t \ge c_O(w_t), H_t \ge c_H(w_t), F_t \ge c_F(w_t)$ 且 $d_t < 30$
- 停泊：无条件（任何网格可执行）
- 作业：仅在 W1/W2/W3 且 $c_t < WM_i$
- 补给：仅在 S1/S2

#### 6.1.3 消耗参数

| 动作 | 正常天气 (O,H,F) | 雷暴天气 (O,H,F) |
|------|:---:|:---:|
| 移动（每格） | (2, 3, 2) | (8, 4, 3) |
| 停泊（每天） | (1, 1, 1) | (3, 3, 2) |
| 作业（每天） | (5, 4, 3) | (8, 6, 6) |

补给价格不变：$p_O=2, p_H=1, p_F=2$

#### 6.1.4 决策函数

$$a_t^* = \arg\max_{a \in A(S_t)} V\big(T(S_t, a, w_t)\big)$$

其中 $V$ 是 CP 前向搜索估计的词典序最优值（先 $\max Z$，再 $\max M$）。CP 搜索假设"剩余天数天气 $\equiv$ 今日观测"，全雷暴/全晴天下等价于确定性全局最优。

#### 6.1.5 状态转移

$$S_{t+1} = T(S_t, a_t^*, w_t)$$

转移规则按动作类型查消耗表扣除资源，作业累加 Z 和 c_t，停泊清零 c_t，补给日触发采购算法（计算到下一补给点或终点所需资源，在载重约束下采购差额）。

#### 6.1.6 在线决策架构

```
for t = 1:30:
    w_t ← 观测当日天气
    若 w_t ≠ w_{t-1} 或无当前计划:
        a_t* ← CP_Search(S_t, assume(w_{t+1:30} = w_t))
    执行 a_t*，更新 S_{t+1}
    if pt == E: 终止
```

### 6.2 在线决策模型 MATLAB 代码：`task2_online_decision.m`

独立文件，文件头注释中即包含上述完整数学模型。依赖 `cp_common.m` 提供 `simulate`、`max_work_with_park`、`enumerate_park_combs` 三个工具函数。

```matlab
function task2_online_decision()
% =========================================================================
%  任务2 — 在线约束规划决策模型（独立版）
%  完整数学模型见文件头注释，此处为核心实现
% =========================================================================

MAX_DAYS = 30; MAX_LOAD = 120;
all_xy = [1 5; 10 5; 2 7; 5 3; 8 8; 3 4; 7 6];
names  = {'B','E','W1','W2','W3','S1','S2'};
WY = [20, 15, 28];  WM = [4, 5, 3];
INIT_O=35; INIT_H=45; INIT_F=30; INIT_M=240; INIT_Z=100;

% 距离矩阵
dist = zeros(7);
for i=1:7, for j=1:7
    dist(i,j)=abs(all_xy(i,1)-all_xy(j,1))+abs(all_xy(i,2)-all_xy(j,2));
end; end
inter_idx = [3 4 5 6 7];

% 消耗参数表
cons_N = struct('MO',2,'MH',3,'MF',2,'PO',1,'PH',1,'PF',1,...
    'WO',5,'WH',4,'WF',3,'pO',2,'pH',1,'pF',2);
cons_T = struct('MO',8,'MH',4,'MF',3,'PO',3,'PH',3,'PF',2,...
    'WO',8,'WH',6,'WF',6,'pO',2,'pH',1,'pF',2);

% ===== 天气序列（修改此行切换场景）=====
weather_mode = 'all_thunder';  % 'all_thunder' | 'all_normal' | 'mixed'
switch weather_mode
    case 'all_thunder', weather_seq = repmat('T', 1, MAX_DAYS);
    case 'all_normal',  weather_seq = repmat('N', 1, MAX_DAYS);
    case 'mixed',       weather_seq = [repmat('T',1,1), repmat('N',1,MAX_DAYS-1)];
end

% ===== 初始化状态 =====
state.pt=1; state.pos=all_xy(1,:);
state.O=INIT_O; state.H=INIT_H; state.F=INIT_F;
state.M=INIT_M; state.Z=INIT_Z; state.consec=0; state.day=0;
plan_path=[]; plan_parks=[]; plan_works=[]; plan_leg=1;
step_in_leg=0; parked_in_leg=0; wp_idx=0; wd_done=0;

fprintf('========================================\n');
fprintf('  任务2 在线CP决策模型（独立版）\n');
fprintf('========================================\n');
fprintf('天气模式: %s\n', weather_mode);
fprintf('模型: S_t = (pt, O,H,F, M,Z, c, w_t, d_t)\n');
fprintf('循环: 观测w_t → CP搜索 → 执行a_t* → S_{t+1}\n\n');

fprintf('--- 逐日在线决策 ---\n');
fprintf('Day | W | Action         | Pos      |  O   H   F  Load |   Z     M\n');
fprintf('----|---|----------------|----------|------------------|------------\n');

% ===== 逐日主循环 =====
while state.day < MAX_DAYS && state.pt ~= 2
    state.day = state.day + 1;
    w = weather_seq(state.day);
    if w == 'T', cons = cons_T; wname = 'thunder';
    else,        cons = cons_N; wname = 'normal';
    end
    act = ''; detail = '';

    % ---- CP 重规划（天气变化或无计划）----
    if isempty(plan_path) || (state.day>1 && w~=weather_seq(max(1,state.day-1)))
        elapsed = state.day - 1;
        init_s = struct('O',state.O,'H',state.H,'F',state.F,'M',state.M,'Z',state.Z);
        [plan_path, plan_parks, plan_works, feasible] = cp_plan(state.pt, elapsed, cons, ...
            dist, inter_idx, WY, WM, MAX_DAYS, MAX_LOAD, init_s);
        if ~feasible, fprintf('无可达方案\n'); break; end
        plan_leg = 1; step_in_leg = 0; parked_in_leg = 0; wp_idx = 0; wd_done = 0;
    end

    if length(plan_path) < 2, break; end
    next_pt = plan_path(plan_leg + 1);

    % ---- 当日动作决策（优先级：作业/停泊重置 → 海上停泊 → 移动）----
    is_work_pt = (state.pt >= 3 && state.pt <= 5);
    need_work  = is_work_pt && wp_idx < length(plan_works) && wd_done < plan_works(wp_idx+1);

    if need_work
        wk_type = state.pt - 2;  % W1→1, W2→2, W3→3
        wm_val = WM(wk_type); yld = WY(wk_type);
        if state.consec < wm_val
            act = sprintf('work(%s)', names{state.pt});
            state.O = state.O - cons.WO; state.H = state.H - cons.WH; state.F = state.F - cons.WF;
            state.Z = state.Z + yld; state.consec = state.consec + 1; wd_done = wd_done + 1;
            if wd_done >= plan_works(wp_idx+1), wp_idx = wp_idx + 1; wd_done = 0; end
        else
            act = 'park(reset)';
            state.O = state.O - cons.PO; state.H = state.H - cons.PH; state.F = state.F - cons.PF;
            state.consec = 0;
        end
    elseif plan_leg <= length(plan_parks) && parked_in_leg < plan_parks(plan_leg)
        act = 'park(at sea)';
        state.O = state.O - cons.PO; state.H = state.H - cons.PH; state.F = state.F - cons.PF;
        state.consec = 0; parked_in_leg = parked_in_leg + 1;
    elseif step_in_leg < dist(state.pt, next_pt)
        state.O = state.O - cons.MO; state.H = state.H - cons.MH; state.F = state.F - cons.MF;
        state.consec = 0; step_in_leg = step_in_leg + 1;
        fr = all_xy(state.pt, :); to = all_xy(next_pt, :);
        dx_tot = to(1)-fr(1); dy_tot = to(2)-fr(2);
        sx = abs(dx_tot); sy = abs(dy_tot);
        if step_in_leg <= sx
            state.pos(1)=fr(1)+sign(dx_tot)*step_in_leg; state.pos(2)=fr(2);
        else
            state.pos(1)=to(1); state.pos(2)=fr(2)+sign(dy_tot)*(step_in_leg-sx);
        end
        act = sprintf('move -> (%d,%d)', state.pos(1), state.pos(2));
        if step_in_leg >= dist(state.pt, next_pt)
            state.pt = next_pt; state.pos = all_xy(next_pt, :);
            step_in_leg = 0; parked_in_leg = 0;
            if state.pt >= 3 && state.pt <= 5
                wc = 0;
                for i = 2:plan_leg+1
                    if plan_path(i) >= 3 && plan_path(i) <= 5, wc=wc+1; end
                end
                wp_idx = wc-1; wd_done = 0;
            end
            if state.pt == 6 || state.pt == 7
                rem_t=0; rem_p=0;
                for k=plan_leg:length(plan_path)-2
                    rem_t=rem_t+dist(plan_path(k+1),plan_path(k+2));
                    if k+1<=length(plan_parks), rem_p=rem_p+plan_parks(k+1); end
                end
                needO=rem_t*cons.MO+rem_p*cons.PO;
                needH=rem_t*cons.MH+rem_p*cons.PH;
                needF=rem_t*cons.MF+rem_p*cons.PF;
                sp=MAX_LOAD-(state.O+state.H+state.F);
                bO=max(0,needO-state.O); bH=max(0,needH-state.H); bF=max(0,needF-state.F);
                if bO+bH+bF<=sp
                    cost=bO*cons.pO+bH*cons.pH+bF*cons.pF;
                    if cost<=state.M
                        state.O=state.O+bO; state.H=state.H+bH; state.F=state.F+bF; state.M=state.M-cost;
                        act=sprintf('SUPPLY(%s)',names{state.pt});
                        detail=sprintf('+O%d H%d F%d cost=%d',round(bO),round(bH),round(bF),round(cost));
                    end
                end
            elseif state.pt == 2, act = 'ARRIVE at E'; end
            plan_leg = plan_leg + 1;
        end
    end

    if state.O<0||state.H<0||state.F<0, act='RESOURCE EXHAUSTED'; end
    if state.O+state.H+state.F>MAX_LOAD+1, act='OVERLOAD'; end

    fprintf('%3d | %s | %-14s | (%2d,%2d)  | %3d %3d %3d %4d | %4d %5d', ...
        state.day, wname, act, state.pos(1), state.pos(2), ...
        round(state.O), round(state.H), round(state.F), ...
        round(state.O+state.H+state.F), state.Z, round(state.M));
    if ~isempty(detail), fprintf('  %s', detail); end
    fprintf('\n');
end

fprintf('----|---|----------------|----------|------------------|------------\n');
fprintf('\n===== 最终结果 =====\n');
if state.pt == 2, fprintf('状态: 第 %d 天抵达 E\n', state.day);
else, fprintf('状态: 未能在 %d 天内抵达 E\n', MAX_DAYS); end
fprintf('Z = %d  M = %d\n', state.Z, round(state.M));
fprintf('\nDone.\n');
end
```

（注：`cp_plan` 和 `cp_search_online` 两个内部函数此处从略，完整代码见 `task2_online_decision.m` 文件。）
