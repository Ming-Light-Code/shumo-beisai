## 方案三：基于混合整数线性规划（MILP）的事件驱动模型

> **最新版本：v6 (2026-07-18)** — 停泊-再作业策略
> - 每作业点访问支持 3 变量：w1（第一段）、b（停泊指示）、w2（第二段）
> - 停泊日消耗 CS=[1,1,1]，收益为 0，作用是打断连续作业计数
> - 约束 w2_j <= b_j * WM_j（线性 big-M），b_j 为二元变量

---

### 1. 方法概述

将问题一分解为两层：

- **外层**：枚举所有可能的路径骨架（停靠点序列）—— 5^k 全枚举，确保覆盖 B 到 E 的所有中间点排列（含重复访问）；
- **内层**：对给定骨架，建立事件驱动的 MILP，调用 intlinprog 同时优化作业天数和采购量。

v6 新增**停泊-再作业策略**：题目规定"单次最多连续作业 WM 天"，停泊（原地不作业，日消耗 O=1,H=1,F=1）可打断连续计数。每作业点访问引入三个决策变量：

- w1_j: 第一段连续作业天数（0..WM_j）
- b_j: 是否插入停泊日（0 或 1）
- w2_j: 第二段连续作业天数（0..WM_j），约束 w2_j <= b_j * WM_j

**收益示例**：W3（WM=3, WY=28）单次访问从 max 84 Z 提升至 max 168 Z（3+stop+3）。

---

### 2. 数学模型

#### 2.1 符号约定

| 符号 | 含义 |
|------|------|
| P = [p_0, ..., p_{m+1}] | 路径骨架，p_0=B, p_{m+1}=E |
| d_i | 第 i 段移动的曼哈顿距离 |
| n_w | 作业停靠点数量 |
| n_s | 补给停靠点数量 |
| CM = (2,3,2) | 每格移动消耗 (O,H,F) |
| CW = (5,4,3) | 每日作业消耗 |
| CS = (1,1,1) | 每日停泊消耗 |
| WY_j | 作业点单日收益 (20, 15, 28) |
| WM_j | 单次最大连续天数 (4, 5, 3) |

#### 2.2 决策变量

- w1_j (整数, 0..WM_j), j=1..n_w — 第一段作业天数
- b_j (二元整数, 0/1), j=1..n_w — 停泊指示
- w2_j (整数, 0..WM_j), j=1..n_w — 第二段作业天数
- buyO_k, buyH_k, buyF_k (整数, >=0), k=1..n_s — 补给站采购量
- O_i, H_i, F_i, M_i (连续, >=0), i=0..m+1 — 离开停靠点后的资源状态

#### 2.3 段间转移方程

```
O_i = O_{i-1} - d_i*CM_O - w1_i*CW_O - b_i*CS_O - w2_i*CW_O + buyO_i
H_i = H_{i-1} - d_i*CM_H - w1_i*CW_H - b_i*CS_H - w2_i*CW_H + buyH_i
F_i = F_{i-1} - d_i*CM_F - w1_i*CW_F - b_i*CS_F - w2_i*CW_F + buyF_i
M_i = M_{i-1} - (2*buyO_i + 1*buyH_i + 2*buyF_i)
```

w1_i, b_i, w2_i 仅当第 i 个停靠点是作业点时非零；buy 同理仅对补给站非零。

#### 2.4 约束条件

**资源非负性**：O_i, H_i, F_i, M_i >= 0  (i=1..m+1)

**载重上限**：O_i + H_i + F_i <= 120  (i=0..m+1)

**总天数限制**：sum(d_i) + sum(w1_j) + sum(b_j) + sum(w2_j) <= 30

**单次作业上限**：w1_j <= WM_j,  w2_j <= WM_j

**停泊-再作业约束**：w2_j <= b_j * WM_j

**补给站到达前非负**（仅补给站）：O_{i-1} >= d_i*CM_O（H、F 同理）

**初始条件**：O_0=35, H_0=45, F_0=30, M_0=240, Z_0=100

#### 2.5 目标函数

- **阶段 1**：max Z = 100 + sum( (w1_j + w2_j) * WY_j )
- **阶段 2**：固定 Z = Z_max，max M_{m+1}

---

### 3. 核心论证

#### 3.1 事件驱动压缩

在任意两个相邻补给站之间，资源只消耗不补充，存量单调非增。段末非负当且仅当段内逐日非负。无需按天展开全部变量。

#### 3.2 停泊-再作业最优性

**命题**：若 b_j = 1，则 w1_j = WM_j 是最优的。

**论证**：停泊日花费 (1,1,1) 且收益为 0，唯一作用是允许第二段作业。第一段越接近上限，单位停泊成本摊薄的产出越高。

#### 3.3 采购整数性

所有采购变量加入 intvars。在整数初始值、整数消耗、整数约束下，最优采购量自然为整数。

### 6. 优化策略总览

| 编号 | 策略 | 类型 | 效果 |
|------|------|------|------|
| O1 | 贪婪预过滤（wdays=0） | 安全剪枝 | 过滤结构不可行骨架 |
| O2 | n_work==0 贪婪直解 | 等价替换 | 省全部 MILP 调用 |
| O3 | 理论上界剪枝 | 安全剪枝 | Z 无法超越时跳过 |
| O4 | seq_len 递增排序 | 启发式 | 早建高 best_Z |
| O5 | 贪心达上限→跳阶段 1 | 等价替换 | 省 1 次 intlinprog |
| SW | 停泊-再作业策略 | 模型增强 | 突破单次 WM 上限 |
