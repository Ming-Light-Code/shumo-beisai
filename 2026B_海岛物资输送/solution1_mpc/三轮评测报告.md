## 二、逻辑自洽性——关键决策链路追踪

### 2.1 O安全检查触发：W2被跳过

```
Day 31: pos=(12,13) -> (15,9) [W2]  Z=280  O=111
Day 41: pos=(16,11) -> (21,16) [S2]  Z=280  O=67
```

**W2(15,9)在Day 31附近到达**。O安全检查计算：
- work_O = 5 × (0.8×5+0.2×8) = 5×5.6 = 28
- move_O(S2) = 13 × 3.2 = 41.6  
- O_needed = 28 + 41.6 + 10 = 79.6
- O_available ≈ 48 (到达W2时)
- **48 < 79.6 → 跳过W2，直接去S2** ✅

**判定**：O安全检查正确触发。船舶不做W2作业，先去S2补给。逻辑自洽。

### 2.2 S2补给 → W3作业

```
Day 41-51: 船从W2附近→S2(21,16)，补给1次
Day 61: pos=(23,23) -> W3(24,24)  Z=280  O=124
```

**问题A（严重）：W2的75Z被永久丢失**

船舶在W2触发O安全检查后被导向S2，路径继续到W3→END，**没有返回W2**。线性路径设计不支持"跳过-返回"模式。
