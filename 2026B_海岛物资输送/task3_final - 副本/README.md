# 任务三：单船场景随机MILP滚动时域MPC模型

## 题目背景

2026年东南大学数学建模竞赛 B 题"海岛物资输送问题" 任务三。

- **海域**：30x30 网格
- **起点** B(1,15)，**终点** E(30,15)
- **补给平台**：S1(12,16)，S2(21,16)
- **作业点位**：W1(6,21)，W2(15,9)，W3(24,24)
- **路点节点**：(10,15)，(15,15)，(20,15) — B→E轴线中间决策点
- **初始资源**：O=100, H=150, F=100, M=750, Z=200
- **载重上限**：400 单位
- **时间限制**：90 天
- **天气**：每日独立，P(正常)=0.8，P(雷暴)=0.2；同天全海域天气相同
- **可观测性**：每日仅能观测当日天气，但已知天气概率先验
- **目标**：先最大化目标物资 Z，再最大化剩余资金 M

## 模型架构

```
每日 MPC 循环:
  1. 生成 K=5 个天气场景 (独立伯努利采样)
  2. 构建随机 MILP (混合整数线性规划):
     +-- 共享决策变量: 位置/移动/作业/采购 (1 份)
     +-- 每场景资源状态: 水/燃料/食物/资金 (K 份)
     +-- 每场景资源平衡方程 (K 份)
     +-- 每场景终端约束 (K 份)
     +-- 机会约束: 每步独立二项分位数资源下界
     +-- Stage 1: 最大化 Z
     +-- Stage 2: 固定 Z，最大化期望 M = sum(M_k)/K
  3. 求解 → 仅执行第 1 天决策 → 观察真实天气 → 次日重新求解
事后: 10000 次蒙特卡洛验证固定策略可靠性
```

## 核心方法

### 1. 宏观网络 (10 个固定节点 + 当前位置)

用功能点和路点代替 900 个网格节点。移动弧时长 = 曼哈顿距离。
- B(1,15), E(30,15)
- S1(12,16), S2(21,16)
- W1(6,21), W2(15,9), W3(24,24)
- WP1(10,15), WP2(15,15), WP3(20,15)

### 2. 场景随机 MILP（核心创新）

MILP 不再使用"期望天气消耗"，而是对 K=5 个独立采样的天气场景分别追踪资源。
路径必须在**所有场景中可行**，天然滤除高风险路径。

```
确定性 MILP:     "平均天气" → 看不到方差 → 可能选高风险路径
场景随机 MILP:   5 个真实天气实现 → 高风险路径在某场景中不可行 → 被排除
```

### 3. 自适应前瞻窗口

H = min(max(min(ceil(remaining*0.4), 30), 20), remaining)

| 任务天数 | H | 覆盖范围 |
|---|---|---|
| 第 1~10 天 | 30 | B→E 直达 + 余量 |
| 第 30 天 | 25 | 两个作业点 + 路径 |
| 第 50 天后 | 20 | 撤离段 |

### 4. 终端 Z 潜力估计

terminalZPotential = max(0, remainingAfterWindow - distToE) * max(reward) * 0.08

为截断视界提供视界外作业收益的估计，引导 MILP 向终点推进。

### 5. 机会约束

每步独立二项分位数：reserve = (binomialQuantile(n, pStorm, alpha) - pStorm*n) * (storm-normal)

保证资源储备随规划时域单调递增。

### 6. 动态撤离天数

evacuationDays = min(40, max(30, 2 * 剩余曼哈顿距离))

### 7. 蒙特卡洛可靠性验证

对固定策略进行 10000 次独立天气仿真，计算 Wilson 95% 置信下界。

## 四轮优化历程

| 轮次 | 变更内容 |
|---|---|
| 第一轮 | 修复机会约束公式bug、移除已承诺目标约束、参数调优、动态撤离天数、ε值修正 |
| 第二轮 | 自适应前瞻窗口、终端进度引导 |
| 第三轮 | 添加B→E轴线路点节点、终端Z潜力估计替换简易进度引导 |
| 第四轮 | 场景随机MILP — K=5场景生成、每场景独立资源状态、期望M最大化 |

## 模型局限性

1. **K=5 场景偏少**：Binomial(H, 0.2) 的采样可能遗漏极端尾部事件
2. **决策变量共享**：未来天数的决策在场景间共享（非真正两阶段随机规划），但每日MPC重规划部分弥补
3. **宏观网络精度**：10 节点 vs 900 格网格，"路过即补给"等策略无法被MILP直接建模
4. **蒙特卡洛事后验证**：未集成到优化循环中
5. **终端Z潜力估计为启发式**：折扣因子 0.08 基于经验而非理论推导
