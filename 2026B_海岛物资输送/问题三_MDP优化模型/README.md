# 问题三：MDP 值迭代优化模型

## 一、问题背景

2026 年东南大学数学建模竞赛 B 题——海岛物资输送问题，任务三。

- 30×30 网格海域，船舶从起点 B(1,15) 出发，须在 90 天内抵达终点 E(30,15)
- 每日天气独立：正常天气概率 0.8，雷暴天气概率 0.2
- 船舶每日仅能观测当日天气，但可利用天气先验概率进行策略优化
- 搭载三种自持资源（燃油 O、淡水 H、食物 F），初始 O=100, H=150, F=100
- 载重上限 400 单位
- 交易资金 M=750，仅用于补给平台采购
- 目标物资 Z=200 初始，可在作业点位增加
- 目标：最大化抵达 E 时的 Z，Z 相同时最大化剩余 M

### 关键节点坐标

| 节点 | 坐标 | 功能 |
|------|------|------|
| B | (1,15) | 起点 |
| E | (30,15) | 终点 |
| W1 | (6,21) | 作业点，产量 20/天，最多连续 4 天 |
| W2 | (15,9) | 作业点，产量 15/天，最多连续 5 天 |
| W3 | (24,24) | 作业点，产量 28/天，最多连续 3 天 |
| S1 | (12,16) | 补给平台 |
| S2 | (21,16) | 补给平台 |

## 二、模型架构

采用 **MDP 逆向归纳 + 启发式精准采购 + 保守作业调度** 的混合架构。

```
┌─────────────────────────────────────────────────────┐
│                  MDP 逆向归纳 (mdp_q3.m)              │
│  状态: (节点, 天气, 资源等级, 天数, 连续作业)         │
│  63,000 状态 × 10 动作 → 0.9s 精确求解               │
│  输出: 最优值函数 V*(s)，用于路由决策                 │
└──────────────────────┬──────────────────────────────┘
                       │ V*(s)
                       ▼
┌─────────────────────────────────────────────────────┐
│              混合仿真引擎 (sim_q3.m)                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────────────┐   │
│  │ MDP 路由 │  │ 精准采购 │  │ 保守作业调度      │   │
│  │ 从B出发  │  │ 缺啥补啥 │  │ E-可达才作业     │   │
│  │ 作业结束 │  │ 节省资金 │  │ 否则回补给/直达E │   │
│  └──────────┘  └──────────┘  └──────────────────┘   │
│  + 30×30 曼哈顿逐格导航 + 逐日天气消耗 + 日志记录    │
└──────────────────────┬──────────────────────────────┘
                       │
                       ▼
              ┌─────────────────┐
              │   result.xls    │
              │ DailyLog+Summary│
              └─────────────────┘
```

## 三、MDP 逆向归纳

### 3.1 状态空间

| 维度 | 取值 | 数量 |
|------|------|------|
| 节点 | B, E, W1, W2, W3, S1, S2 | 7 |
| 天气 | 正常, 雷暴 | 2 |
| 资源等级 | 1–10（阈值 [40,80,...,360]） | 10 |
| 天数 | 1–90 | 90 |
| 连续作业 | 0,1,2,...,4+ | 5 |
| **总计** | | **63,000** |

### 3.2 动作空间

- **MOVE(target)**：原子跳转到目标节点，消耗期望资源（距离 × 加权期望消耗率）
- **PARK**：原地停泊，重置连续作业计数
- **WORK**：在当前作业点工作（需遵守 maxC 约束）
- **SUPPLY**：在补给点采购资源（MDP 中建模为等级提升 + 成本惩罚）

### 3.3 算法

采用 **逆向归纳（Backward Induction）** 替代值迭代：

```
for day = 90 downto 1:
    for each state at day:
        V(state) = max_action [ R(state, action) + E[V(next_state)] ]
```

- V(E, ·) = 0（终点无额外收益，Z 已通过作业累积）
- 不可达 E 的状态：V = -1e6
- γ = 1.0（有限时域无需折扣）
- 时间复杂度：O(状态数 × 动作数) = 63,000 × ~7 = ~440K 次评估
- 训练时间：0.9 秒

## 四、混合仿真引擎

### 4.1 精准采购策略

在补给平台，不采用"填满至载重上限"的粗放策略，而是**精准计算下一作业循环的需求**：

```
need = travel_to_work + one_work_cycle + return_to_supply
buy  = max(0, need − current)
```

- 运行消耗使用 50/50 雷暴加权保守估计 + SAFETY=1.3 安全边际
- 返回补给消耗使用 SAFETY_EXIT=1.0（松弛，作为逃生通道）
- 受载重上限和资金双重约束

**效果**：M 从原来恒为 0 变为均值 84，最高节省 158 资金。

### 4.2 保守作业调度

作业仅在满足 **E-可达安全条件** 时执行：

```
can_work = (O > dE × 5 × 1.3)  ∧  (H > dE × 3.5 × 1.3)  ∧  (F > dE × 2.5 × 1.3)
         ∧ (day + dE < 88)
         ∧ (cw < maxC)
```

即：作业后剩余资源仍足够安全抵达 E，且有足够时间。

### 4.3 补给回路退出

当无法继续作业且资源不足以直达 E 时，检查是否可返回最近补给点：

```
can_return = (O > dS × 5 × 1.0)  ∧  (H > dS × 3.5 × 1.0)  ∧  (F > dS × 2.5 × 1.0)
           ∧ (day + dS + dist(S,E) < 88)
```

这为船舶提供了安全逃生通道，避免困死在作业点。

## 八、模型特点与局限

### 优点
- MDP 逆向归纳在 63,000 状态空间上数学严谨，0.9 秒求解
- 精准采购策略使资金从 0 恢复到均值 84
- 保守作业检查确保 100% 抵达率
- 完整的 30×30 网格导航和 result.xls 输出

### 局限
- Z 收益受载重上限（400）结构性约束，均值仅 246（初始 200）
- MDP 仅用于路由决策，作业/补给为启发式
- MOVE 动作建模为原子跳转，未考虑中途改道
- 资源离散化（10 档）仍有量化误差
