# 方案一：骨架枚举 + 期望消耗 MILP + 天气自适应仿真

## 核心思想

将随机天气问题转化为确定性等价问题：
1. 使用**期望消耗系数**替代随机消耗
2. 对每条路径骨架求解两阶段 MILP
3. 输出最优宏观计划
4. 通过 Monte Carlo 仿真验证在随机天气下的鲁棒性

## 期望消耗计算

P(正常)=0.8, P(雷暴)=0.2

- E[移动O] = 0.8×2 + 0.2×8 = 3.2
- E[移动H] = 0.8×3 + 0.2×4 = 3.2
- E[移动F] = 0.8×2 + 0.2×3 = 2.2
- E[停泊O] = 0.8×1 + 0.2×3 = 1.4
- E[停泊H] = 0.8×1 + 0.2×3 = 1.4
- E[停泊F] = 0.8×1 + 0.2×2 = 1.2
- E[作业O] = 0.8×5 + 0.2×8 = 5.6
- E[作业H] = 0.8×4 + 0.2×6 = 4.4
- E[作业F] = 0.8×3 + 0.2×6 = 3.6

## 骨架枚举

从 {W1,W2,W3,S1,S2} 中选择最多 max_seq 个点排列为路径。
max_seq = floor((90 - min_B_inter - min_inter_E) / min_ii) + 1

`min_B_inter` = min(B到中间点的距离) = 11 (B→W1)
`min_inter_E` = min(中间点到E的距离) = 15 (W3→E)
`min_ii` = min(中间点之间的距离) = 11 (S1→W1, W3→S2, 等)

max_seq = floor((90-11-15)/11) + 1 = floor(64/11) + 1 = 6

总共骨架数 = Σ 5^k, k=0..6 = 19531

## 两阶段 MILP

- 阶段1：Max Z（先求最大目标物资）
- 阶段2：Max M s.t. Z=Z_max（再求最大剩余资金）

## 天气自适应仿真

在线策略规则：
1. 如遇雷暴且资源紧张（< 30%载重上限）：停泊等待
2. 如已达到作业点且资源充足、连续作业未达上限：作业
3. 否则：按计划路径移动
4. 到补给站时按计划采购
