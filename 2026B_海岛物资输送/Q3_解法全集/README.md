# Q3 解法全集 —— 天气随机先验信息已知条件下的规划

## 问题概述

**任务3（Q3）** 在 30×30 海域中，船舶从 B(1,15) 出发到达 E(30,15)，限时 90 天。
每日天气独立同分布：P(正常)=0.8, P(雷暴)=0.2。船舶仅观测当日天气，不能预知未来，
但可利用概率先验优化策略。

**目标**：先最大化抵达时目标物资 Z，再最大化剩余资金 M。

| 参数 | 值 |
|------|-----|
| 网格 | 30×30 |
| 起点 B | (1, 15) |
| 终点 E | (30, 15) |
| 补给平台 | S1(12,16), S2(21,16) |
| 作业点 | W1(6,21), W2(15,9), W3(24,24) |
| 初始资源 | O=100, H=150, F=100, M=750, Z=200 |
| 载重上限 | 400 |
| 时间上限 | 90 天 |

## 方案一：骨架枚举 + 期望消耗 MILP（推荐）

### 数学模型

将随机天气问题转化为确定性等价问题：使用**期望消耗系数**替代实际消耗。

期望移动消耗：E[O]=0.8×2+0.2×8=3.2, E[H]=3.2, E[F]=2.2
期望停泊消耗：E[O]=0.8×1+0.2×3=1.4, E[H]=1.4, E[F]=1.2
期望作业消耗：E[O]=0.8×5+0.2×8=5.6, E[H]=4.4, E[F]=3.6

对每条路径骨架求解两阶段 MILP：
- **阶段1**：最大化 Z
- **阶段2**：固定 Z，最大化 M

## 方案二：MDP + Rollout 策略

### 数学模型

将问题建模为有限时域 MDP：状态 s_t = (x,y,O,H,F,M,Z,c1,c2,c3,t)，
动作 a ∈ {Move(R/L/U/D), Stop, Work, Supply}。

使用 **Rollout 算法** 在线决策：
1. 以方案一的 MILP 结果为 Base Policy π₀
2. 在每个状态 s_t，对每个候选动作 a：
   - 模拟 N 条后续天气轨迹
   - 每条轨迹按 π₀ 执行到终点
   - 计算平均 Z 和 M
3. 选择期望 Z 最大（M 为 tiebreaker）的动作

Rollout 的 Policy Improvement Property 保证效果不差于 π₀。

### 运行方式

```bash
cd "C:/Users/ming/Desktop/Q3_解法全集/方案二_MDP_Rollout"
python rollout_q3.py
```

## 方案四：Q-Learning

### 数学模型

23 维状态特征（归一化位置、距离、资源、时间）+ 7 个离散动作。
使用线性函数近似的 Q-Learning（Linear FA Q-Learning）：

Q(s,a) ≈ w_a · φ(s)

更新规则：w_a ← w_a + α(r + γ·max Q(s',a') - Q(s,a)) φ(s)

## 关键分析

### 路径可行性

| 路线 | 曼哈顿距离 | 仅移动天数 |
|------|----------|-----------|
| B→E 直走 | 29 | 29 |
| B→W1→W2→W3→E | 71 | 71 |
| B→S1→W1→W2→S2→W3→E | 83 | 83 |

90 天限制下，选择 "B→S1→W1→W2→S2→W3→E" 仅剩 7 天可用于作业+停泊。
若跳过 S1 或 S2，可节省约 10-12 天。

### 天气影响

- 期望消耗下，B→E 直走 29 步需约 93 O，而初始 O=100 → 刚好可行但无余量
- 雷暴日移动消耗是正常的 4 倍（O: 8 vs 2），导致资源规划高度敏感
- 模拟验证的必要性：期望消耗下的最优计划在实际随机天气中可能不可行

### 连续作业上限利用

- W3 产出 28 Z/天但只能连做 3 天
- 若在 W3 做 "3天作业→1天离开再返回→3天作业" 循环：
  - 每 4 天产出 84，日均 21 > W1 的 20 > W2 的 15
  - 但额外移动消耗资源，需评估是否净赚
