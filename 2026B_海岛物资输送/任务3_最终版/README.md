## 方法论

三层模型共享统一的CP搜索核心（路径骨架→三剪枝→simulate→词典序择优），继承任务1/2已建立的框架：

- **离线CP**：期望消耗参数 + 上界剪枝 → 全局最优 Z=652
- **在线决策**：滚动时域重规划 + 三资源生存检查 + 场景CP + 预算自适应补给
- **MC验证**：共享引擎，批量统计

## 关键改进（相对原版）

| 改进 | 效果 |
|------|------|
| 补给采购按预算缩放 | 资金不足时按比例缩减而非直接失败 |
| 多层回退链 (场景→期望→正常+生存) | 大幅降低"NO PLAN"概率 |
| init_s 状态传递 | CP搜索使用实际当前资源 |
| 补给统一调用 get_supply_needs | 消除三方代码不一致 |
| 三资源生存检查(O/H/F) | 防止非O资源耗尽 |
| SAFETY=1.05 轻度保守 | 5%裕度吸收温和天气偏差 |

## 已知限制

期望值CP对连续雷暴的方差处理能力有限——40%的MC失败全部为资源耗尽。
根本解决方案是MDP/随机动态规划，这是未来工作的方向。
