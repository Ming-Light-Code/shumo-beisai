# RSO 滚动随机优化方案 v5 — 骨架随机规划 (SBSP)

## 问题背景
2026B 海岛物资输送问题 任务3：30x30 网格，随机天气 (P(N)=0.8, P(T)=0.2)，90 天内从 B 到 E 最大化目标物资 Z。

## v5 方法：骨架枚举 + 自适应策略 + 蒙特卡洛评估

v5 对原 RSO 方案进行了根本性重构。原方案的核心缺陷——短视时域(H=24)、忽略 M 目标、尾部贪婪近似——被全部消除。

### 算法流程
`
Phase 1 — 骨架枚举:
  深度优先搜索所有可行的路径骨架 (B -> {W1,W2,W3,S1,S2}* -> E)
  约束: 旅行天数 <= 90，禁止连续补给点，到达E后停止

Phase 2 — 骨架评估:
  For each skeleton:
    运行 N=300 次蒙特卡洛仿真
    每次仿真使用自适应在线策略:
      - 工作点: 正常天作业, 雷暴天停泊, 剩余时间充足则继续
      - 补给点: 以雷暴消耗为基准计算需求，在载重和资金约束下采购
      - 移动: 曼哈顿最短路径逐格移动
    统计: 成功率, E[Z], E[M]

Phase 3 — 择优:
  词典序 (max E[Z], then max E[M]) 选择最优骨架
`

### 与原 RSO (v4) 的关键区别

| 维度 | v4 (MPC) | v5 (SBSP) |
|------|----------|-----------|
| 规划时域 | 24 天 (短视) | 90 天 (全时域骨架) |
| 目标函数 | 仅 max Z | 词典序 (Z, M) |
| 尾部策略 | 贪婪启发式 | 完整骨架 + 自适应策略 |
| 补给决策 | 固定 70/30 混合 | 雷暴消耗基准 + 安全系数 |
| 终端约束 | 不保证到达 E | 骨架保证路径连通 |
| 可运行性 | 代码有bug | 已验证可运行 |

### 运行结果

`
骨架数: 379  搜索节点: 379  MC/骨架: 300  总耗时: ~12s

最优骨架:  B -> S1 -> W3 -> S2 -> W3 -> S2 -> E
  E[Z] = 340.0   E[M] = 109.3   成功率 = 0.7%
  旅行: 75天  剩余: 15天

对比参考:
  CP期望值方案: Z=480 (确定性, 高估)
  MDP方案:      E[Z]=359.2, M=240.7, 成功率100%
  SBSP(本方案): E[Z]=340.0, M=109.3, 成功率0.7%
`

说明: SBSP 的最优骨架与 CP 期望值方案相同 (B->S1->W3->S2->W3->S2->E)，但期望 Z 较低。这是因为 MC 模拟使用实际天气（含雷暴天），雷暴天在作业点只能停泊、在工作点不能作业，导致有效作业天数显著低于期望值计算。该骨架成功率仅 0.7%，说明两次访问 W3 在随机天气下非常危险。

更高成功率的替代: B->S1->W1->S1->W1->S1->E (成功率 50.7%, E[Z]=326.1)。

### 策略说明

**工作策略**: 在工作点 W_i，正常天气作业 (消耗 cW，收益 WY_i)，雷暴天气停泊 (消耗 cP < cW)，连续作业达 WM_i 天后自动停泊一日重置计数器。当剩余天数 <= 到E所需旅行天数 + 缓冲(5天) 时离开。

**补给策略**: 到达补给点 S_i 后，以雷暴消耗为基准计算到下一个关键节点所需的资源量，在载重和资金约束下最大化采购量。采用雷暴基准确保极端天气下也有足够资源。

**移动策略**: 节点间使用曼哈顿最短路径，先 x 方向后 y 方向逐格移动。

### 适用场景
- 需要全时域保证到达终点的约束优化问题
- 天气随机但对策略解释性有要求的场景
- 适合竞赛论文的均衡方案 (可解释 + 可验证 + 可运行)
