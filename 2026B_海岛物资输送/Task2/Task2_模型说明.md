## Task 2：仅考虑当日天气可观测条件下的策略设计

### 1. 问题重述

在 Task 1 的基础上加入天气影响。天气分为正常和雷暴两类，船舶每日行动前仅能观测**当日**天气，无法预知未来。两类天气均允许移动、停泊、补给、作业，但消耗不同：

| 行为 | 正常天气 (O,H,F) | 雷暴天气 (O,H,F) |
|------|-----------------|-----------------|
| 移动一格 | (2,3,2) | (8,4,3) |
| 原地停泊 | (1,1,1) | (3,3,2) |
| 作业一日 | (5,4,3) | (8,6,6) |

**特别要求**：以连续 30 天均为雷暴天气的极端场景，给出最优航行方案。

---

### 2. 模型设计思路

#### 2.1 两阶段分析

Task 2 实际包含两个子问题：

**子问题 A（通用模型）**：考虑实时天气观测的在线决策框架
- 无法预知未来天气，每日需根据 (位置, 资源, 当日天气) 做出行动决策
- 在缺乏天气概率先验（Task 3 才给出）的条件下，可采用**鲁棒/极小化极大**策略

**子问题 B（极端雷暴）**：连续 30 天雷暴的确定性场景
- 天气完全已知（全部雷暴），退化为确定性问题
- 可直接用 MILP 精确求解，仅需将消费参数替换为雷暴数值

#### 2.2 通用在线决策模型（子问题 A）

定义状态：

    state(t) = (x, y, O, H, F, M, Z, w_consec, weather_today)

每日决策：

    a(t) in {Move(4dir), Stop, Supply(buy), Work}

由于未来天气未知（且 Task 2 未给概率），最优策略采用以下方法之一：

- **鲁棒策略**：假设未来全部为雷暴（最坏情况），按确定性子问题 B 求解，得到一条在任何天气下均可行的保守方案
- **乐观-鲁棒折衷**：用正常天气计算一条参考路径，实时遇到雷暴时启用保守预案（如停泊等待或绕行补给）
- **滚动时域**：每步用剩余天数、当前资源、当日天气，贪婪优化当日决策

本题焦点是子问题 B（全雷暴确定解），子问题 A 提供模型框架。

#### 2.3 全雷暴确定性模型（子问题 B）

天气确定（全部雷暴），直接应用 v6 MILP 框架，仅替换消费参数：

    CM_storm = [8, 4, 3]    // 移动消耗（正常: [2,3,2]）
    CS_storm = [3, 3, 2]    // 停泊消耗（正常: [1,1,1]）
    CW_storm = [8, 6, 6]    // 作业消耗（正常: [5,4,3]）

模型其余不变：10x10 海域、同一点位、初始资源不变、载重 120 不变、30 天不变、停泊-再作业策略不变。

**关键约束收紧**：
- B->S1 需 3 格 = 24 O，初始 O=35 -> 可行但仅余 11 O
- B->S2 需 8 格 = 64 O，初始 O=35 -> 不可直达
- B->E 直走需 9 格 = 72 O -> 不可行

高消耗迫使路径必须优先抵达补给站，且作业收益的性价比大幅降低。

---

### 3. MILP 模型（全雷暴）

沿用 Task 1 v6 的停泊-再作业 MILP 框架，仅消费参数替换。

段间转移方程：

    O_i = O_{i-1} - d_i*8 - w1_i*8 - b_i*3 - w2_i*8 + buyO_i
    H_i = H_{i-1} - d_i*4 - w1_i*6 - b_i*3 - w2_i*6 + buyH_i
    F_i = F_{i-1} - d_i*3 - w1_i*6 - b_i*2 - w2_i*6 + buyF_i
    M_i = M_{i-1} - (2*buyO_i + 1*buyH_i + 2*buyF_i)

约束、目标函数两阶段优化、优化策略（O1-O5+SW）全部保留。

---

### 4. 算法流程

    1. 设定雷暴消费参数 CM=[8,4,3], CS=[3,3,2], CW=[8,6,6]
    2. 可达性预检：B 到最近补给站 (S1) 需 24 O <= 35
    3. 骨架枚举（max_seq 基于曼哈顿距离，过滤条件不变）
    4. 对每条骨架：
       a. 上界剪枝（O3）
       b. n_work==0 贪婪直解（O2）
       c. wdays=0 预过滤（O1）
       d. 贪心最大工作天数 -> 若达上限跳阶段 1（O5）
       e. 否则完整两阶段 MILP
    5. 输出最优解及逐日排程
