# 数模备赛

数学建模竞赛备赛资料与代码仓库，按题目和年份整理。

## 目录结构

- `2026A_无人机烟幕/`：2026 A 题“无人机烟幕干扰弹”相关资料
  - `题目与附件/`：赛题照片与附件
  - `求解代码/`：A题求解、25A_code、appendix_code、支撑材料、支撑资料
  - `示意图与脚本/`：绘图脚本与示意图源文件
- `2026B_海岛物资输送/`：2026 B 题“海岛物资输送”各任务方案
  - 顶层各方案目录：Task1_CP、Task2、task3_*、MILP方案三、Q3_解法全集 等
  - `报告文档/`：方案说明、解法说明、报告
  - `求解代码/`：任务 1-4 求解脚本
  - `运行结果/`：xlsx、json、npy 等结果文件
  - `示意图/`：figures 与示意图产出
- `2024A_板凳龙/`：2024 A 题练习代码（旧版文件、24A_harness）
- `历年赛题/`：B、C、D、E 题题目与附件；2023B_多波束测线练习
- `2026校赛/`：2026 校内赛题目与附件
- `备赛练习草稿/`：练习资料与优秀论文截图

## 说明

- 论文、PDF、LaTeX 编译依赖（cls、字体、中间文件）、压缩包、视频等不纳入仓库，仅保留在本地。
- 涉及个人信息的内容（报名号、姓名等）不上传。
